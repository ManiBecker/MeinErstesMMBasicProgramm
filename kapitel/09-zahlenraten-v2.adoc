== Zahlenraten Version 2

image::bilder/09_zahlenraten_v2.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* wann eine `DO ... LOOP`-Schleife verwendet wird
* wie eine Schleife mit `UNTIL` oder `WHILE` gesteuert wird
* warum die Position der Bedingung eine Rolle spielt
* wie ein Spiel mehrere Versuche erlauben kann
* wie Hinweise ausgegeben werden
* wie die Anzahl der Versuche gezählt wird

Am Ende des Kapitels hast du ein deutlich verbessertes Zahlenratespiel programmiert.

=== Das Problem

In unserem ersten Zahlenratespiel hatte der Spieler nur einen einzigen Versuch.

War die Eingabe falsch, war das Spiel sofort beendet.

Das ist nicht besonders spannend.

Wir möchten dem Spieler deshalb mehrere Versuche erlauben.

=== Die neue Spielidee

Der Computer denkt sich wieder eine Zahl aus.

Der Spieler darf so lange raten, bis er die richtige Zahl gefunden hat.

Zusätzlich erhält er hilfreiche Hinweise:

* Zu klein!
* Zu groß!
* Richtig!

=== Eine neue Schleife

In Kapitel 6 haben wir die Schleife `FOR ... NEXT` kennengelernt.

Sie eignet sich besonders dann, wenn bereits vorher feststeht, wie oft etwas
wiederholt werden soll:

[source,basic]
----
FOR I=1 TO 10
  PRINT I
NEXT I
----

Beim Zahlenratespiel wissen wir dagegen nicht, wie viele Versuche der Spieler
benötigen wird.

Für solche Aufgaben eignet sich die
indexterm:[DO]indexterm:[LOOP] Schleife `DO ... LOOP`.

Die einfachste Form sieht so aus:

[source,basic]
----
DO

  PRINT "Hallo Welt!"

LOOP
----

indexterm:[Schleifenbedingung]
indexterm:[Endlosschleife]

[IMPORTANT]
====
Diese Schleife besitzt keine Schleifenbedingung
und läuft deshalb als Endlosschleife immer weiter.

Eine Schleifenbedingung legt fest, wie lange eine Schleife ausgeführt wird.

Eine Schleife kann mit `CTRL+C` abgebrochen werden.
====

`DO ... LOOP` eignet sich besonders für Wiederholungen, bei denen die Anzahl
der Durchläufe vorher nicht bekannt ist.

=== Die Schleife beenden

Natürlich soll eine Schleife normalerweise nicht endlos laufen.

Mit indexterm:[UNTIL] `UNTIL` können wir festlegen, wann die Schleife beendet
werden soll.

[source,basic]
----
DO

  INPUT A

LOOP UNTIL A=10
----

Das Programm fordert so lange eine Zahl an, bis die Zahl 10 eingegeben wird.

`UNTIL` bedeutet sinngemäß „bis“. Die Schleife läuft also:

----
Wiederhole ...
bis A=10
----

[IMPORTANT]
====
Bei `LOOP UNTIL` wird die Bedingung erst am Ende der Schleife geprüft.

Die Anweisungen zwischen `DO` und `LOOP` werden deshalb mindestens einmal
ausgeführt.
====

=== Wiederholen mit WHILE

Neben `UNTIL` können wir eine `DO ... LOOP`-Schleife auch mit
indexterm:[WHILE] `WHILE` steuern.

`WHILE` bedeutet sinngemäß „so lange“.

[source,basic]
----
A=1

DO

  PRINT A
  A=A+1

LOOP WHILE A<=5
----

Die Ausgabe lautet:

[source]
----
1
2
3
4
5
----

Die Schleife wird wiederholt, so lange die Bedingung `A<=5` erfüllt ist.

Damit unterscheiden sich `UNTIL` und `WHILE` vor allem in der Bedeutung:

[cols="1,3"]
|===
|`UNTIL` |wiederholen, bis die Bedingung wahr wird
|`WHILE` |wiederholen, so lange die Bedingung wahr ist
|===

Bei `UNTIL` beschreibt die Bedingung also, wann die Schleife _enden_ soll.
Bei `WHILE` beschreibt sie dagegen, unter welcher Bedingung die Schleife
_weiterlaufen_ soll.

==== Die Bedingung kann auch am Anfang stehen

Die Bedingung einer `DO ... LOOP`-Schleife kann auch bereits bei `DO`
angegeben werden:

[source,basic]
----
A=1

DO WHILE A<=5

  PRINT A
  A=A+1

LOOP
----

Hier wird die Bedingung geprüft, bevor die Anweisungen innerhalb der Schleife
ausgeführt werden.

Ist die Bedingung bereits beim ersten Test nicht erfüllt, wird die Schleife
kein einziges Mal durchlaufen.

Bei einer Bedingung hinter `LOOP` wird der Schleifeninhalt dagegen mindestens
einmal ausgeführt.

[NOTE]
====
Auch `UNTIL` kann direkt hinter `DO` verwendet werden:

[source,basic]
----
DO UNTIL BEDINGUNG
  ...
LOOP
----

Damit kann die Bedingung sowohl am Anfang als auch am Ende einer
`DO ... LOOP`-Schleife geprüft werden.

Welche Form besser geeignet ist, hängt davon ab, ob der Schleifeninhalt 
auf jeden Fall mindestens einmal ausgeführt werden soll.
====

=== Das neue Zahlenratespiel

Nach so viel Schleifentheorie wird es Zeit, wieder zu programmieren.

Jetzt kennen wir die wichtigsten Grundlagen der `DO ... LOOP`-Schleife und
können sie in unserem Zahlenratespiel einsetzen.

Da wir vorher nicht wissen, wie viele Versuche der Spieler benötigen wird,
verwenden wir eine Schleife mit `LOOP UNTIL`. Das Spiel fragt dadurch so lange
nach einem neuen Tipp, bis die geheime Zahl gefunden wurde.

Unser verbessertes Zahlenratespiel sieht damit so aus:

[source,basic]
----
GEHEIM=INT(RND*100)+1

PRINT "Ich habe mir eine Zahl von 1 bis 100 ausgedacht."

DO

  INPUT TIPP

  IF TIPP<GEHEIM THEN
    PRINT "Zu klein!"
  ELSEIF TIPP>GEHEIM THEN
    PRINT "Zu gross!"
  ELSE
    PRINT "Richtig!"
  ENDIF

LOOP UNTIL TIPP=GEHEIM
----

=== Das Programm verstehen

Wie bisher wird zunächst eine Zufallszahl erzeugt.

[source,basic]
----
GEHEIM=INT(RND*100)+1
----

Danach beginnt die Schleife:

[source,basic]
----
DO
...
LOOP UNTIL TIPP=GEHEIM
----

Die Schleife wird so lange wiederholt, bis der Spieler die richtige Zahl eingegeben hat.

=== Die Anzahl der Versuche zählen

Wie viele Versuche benötigt der Spieler?

Das können wir mit einer Variablen zählen.

[source,basic]
----
VERSUCHE=0

DO

  VERSUCHE=VERSUCHE+1

  INPUT TIPP

  IF TIPP<GEHEIM THEN
    PRINT "Zu klein!"
  ELSEIF TIPP>GEHEIM THEN
    PRINT "Zu gross!"
  ELSE
    PRINT "Richtig!"
  ENDIF

LOOP UNTIL TIPP=GEHEIM

PRINT
PRINT "Du hast ";VERSUCHE;" Versuche benoetigt."
----

=== Das Spiel ausprobieren

Starte das Programm mehrfach.

Wie viele Versuche benötigst du?

Schaffst du es in weniger als fünf Versuchen?

=== Eine persönliche Begrüßung

Das Spiel kann den Spieler auch persönlich begrüßen.

[source,basic]
----
PRINT "Wie heisst du?"
INPUT NAME$

PRINT
PRINT "Hallo ";NAME$

GEHEIM=INT(RND*100)+1
VERSUCHE=0

DO

  VERSUCHE=VERSUCHE+1

  INPUT TIPP

  IF TIPP<GEHEIM THEN
    PRINT "Zu klein!"
  ELSEIF TIPP>GEHEIM THEN
    PRINT "Zu gross!"
  ELSE
    PRINT "Richtig!"
  ENDIF

LOOP UNTIL TIPP=GEHEIM

PRINT
PRINT "Du hast ";VERSUCHE;" Versuche benoetigt."
----

[TIP]
====
Viele Programme entstehen nicht auf einmal.

Oft beginnt man mit einer einfachen Version und erweitert diese Schritt für Schritt.

Genau so ist auch unser Zahlenratespiel entstanden.
====

=== Experimentiere!

Probiere folgende Änderungen aus:

* Verwende Zahlen von 1 bis 50.
* Verwende Zahlen von 1 bis 1000.
* Begrenze die Anzahl der Versuche.
* Vergib Punkte für besonders gute Ergebnisse.

=== Probier's selbst!

Versuche folgende Aufgaben:

. Begrenze die Anzahl der Versuche auf 10.
. Gib nach dem Spiel die geheime Zahl aus.
. Vergib Punkte abhängig von der Anzahl der Versuche.
. Frage nach jedem Spiel, ob noch einmal gespielt werden soll.
. Erweitere das Spiel um einen Highscore.

=== Zusammenfassung

In diesem Kapitel hast du unser erstes Spiel verbessert.

Du hast gelernt:

* `DO ... LOOP` für Wiederholungen mit unbekannter Anzahl von Durchläufen zu verwenden
* Schleifen mit `UNTIL` zu wiederholen, bis eine Bedingung erfüllt ist
* Schleifen mit `WHILE` zu wiederholen, so lange eine Bedingung erfüllt ist
* Bedingungen am Anfang oder am Ende einer `DO ... LOOP`-Schleife zu prüfen
* Hinweise auszugeben
* Versuche zu zählen
* Programme schrittweise zu erweitern
