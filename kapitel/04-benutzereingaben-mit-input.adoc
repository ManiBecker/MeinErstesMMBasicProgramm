== Benutzereingaben mit INPUT

image::bilder/04_benutzereingaben_mit_input.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* wie Daten vom Benutzer eingegeben werden
* wie die Anweisung `INPUT` verwendet wird
* wie Eingaben in Variablen gespeichert werden
* wie Zahlen und Texte eingegeben werden
* warum eine Eingabe zum Datentyp der Variablen passen muss
* wie mit `VAL()` Text in eine Zahl umgewandelt wird
* wie mit `STR$()` eine Zahl in Text umgewandelt wird
* wie Eingaben weiterverarbeitet werden

Am Ende des Kapitels kannst du eigene interaktive Programme schreiben.

=== Warum Benutzereingaben wichtig sind

Bisher standen alle Werte fest im Programm.

Zum Beispiel:

[source,basic]
----
A=10
B=20
PRINT A+B
----

Das Ergebnis ist immer gleich.

Interessanter wird es, wenn der Benutzer die Werte selbst eingeben kann.

=== Unsere erste Eingabe

Die Anweisung indexterm:[INPUT] `INPUT` wartet auf eine Eingabe des Benutzers.

Gib folgendes ein:

[source,basic]
----
INPUT A
PRINT A
----

MMBasic zeigt ein Fragezeichen an:

[source]
----
?
----

Gib nun beispielsweise die Zahl `42` ein und bestätige mit der Eingabetaste.

Auf dem Bildschirm sieht das so aus:

[source]
----
? 42
42
----

Die erste `42` ist deine Eingabe. Die zweite wird anschließend mit `PRINT`
ausgegeben.

=== Eingaben in Variablen speichern

Die eingegebene Zahl wird in der Variablen `A` gespeichert.

[source,basic]
----
INPUT A
PRINT A
----

Wenn du beispielsweise `100` eingibst, enthält `A` anschließend den Wert 100.

==== Die Eingabe muss zum Datentyp passen

Im vorherigen Kapitel hast du gelernt, dass Variablen unterschiedliche
Datentypen besitzen können. Das spielt auch bei `INPUT` eine wichtige Rolle.

Bei

[source,basic]
----
INPUT A
----

erwartet MMBasic eine Zahl. Gibst du beispielsweise `42` ein, kann dieser
Wert problemlos in `A` gespeichert werden.

Was passiert aber, wenn du stattdessen einen Text eingibst?

[source]
----
? Hallo
----

MMBasic kann den Text `Hallo` nicht als Zahl in der numerischen Variablen `A`
speichern. Die Eingabe schlägt deshalb fehl.

Wenn du Text erfassen möchtest, musst du eine String-Variable verwenden:

[source,basic]
----
INPUT NAME$
----

Dann ist beispielsweise diese Eingabe möglich:

[source]
----
? Manfred
----

[IMPORTANT]
====
Der Datentyp der Variablen bestimmt, welche Art von Eingabe `INPUT` erwartet.

* Eine numerische Variable wie `A` erwartet eine Zahl.
* Eine String-Variable wie `NAME$` erwartet Text.

Die Eingabe muss also zum Datentyp der Variablen passen.
====

=== Text und Zahlen umwandeln

Manchmal liegt eine Zahl nicht als numerischer Wert, sondern als Text vor.
Zum Beispiel kann der String `"42"` in einer String-Variablen gespeichert
sein:

[source,basic]
----
EINGABE$="42"
----

Mit indexterm:[VAL()] `VAL()` kann ein solcher Text in einen Zahlenwert
umgewandelt werden:

[source,basic]
----
EINGABE$="42"
ZAHL=VAL(EINGABE$)

PRINT ZAHL
PRINT ZAHL+8
----

Ausgabe:

[source]
----
42
50
----

`VAL()` liest den Zahlenwert am Anfang eines Strings und liefert ihn als
numerischen Wert zurück.

Die umgekehrte Richtung ist ebenfalls möglich. Mit indexterm:[STR$()]
`STR$()` kann ein Zahlenwert in einen String umgewandelt werden:

[source,basic]
----
ZAHL=42
TEXT$=STR$(ZAHL)

PRINT TEXT$
----

Ausgabe:

[source]
----
42
----

Damit stehen uns zwei wichtige Funktionen zur Umwandlung zur Verfügung:

[cols="2,3,3",options="header"]
|===
|Funktion |Umwandlung |Beispiel

|`VAL()`
|String → Zahl
|`ZAHL=VAL("42")`

|`STR$()`
|Zahl → String
|`TEXT$=STR$(42)`
|===

[TIP]
====
`VAL()` und `STR$()` werden dir in späteren Programmen noch häufiger
begegnen. Für den Moment genügt es, sich die beiden Richtungen zu merken:

`VAL()` macht aus einem Zahlentext eine Zahl, `STR$()` aus einer Zahl einen
String.
====

=== Mit Eingaben rechnen

Eingegebene Werte können sofort weiterverarbeitet werden.

[source,basic]
----
INPUT A
PRINT A*2
----

Beispiel:

[source]
----
? 21
42
----

=== Zwei Werte eingeben

Natürlich können auch mehrere Werte eingegeben werden.

[source,basic]
----
INPUT A, B

PRINT A+B
----

Beispiel:

[source]
----
? 10, 20
30
----

Da ein Benutzer nicht erkennen kann, in welcher Form die Eingabe nach dem
`?`-Prompt anzugeben ist, kann dem `INPUT`-Befehl auch ein Fragetext mitgegeben
werden. Die Syntax ist dabei:

[source]
----
INPUT ["prompt$(;|,)] var1 [, var2[, var3[, etc]]]
----

Normalerweise wird der Fragetext mit einem Semikolon (`;`) abgeschlossen. In
diesem Fall wird hinter dem Fragetext ein Fragezeichen angezeigt.

[source,basic]
----
INPUT "Bitte gib zwei Zahlen ein, getrennt durch ein Komma: "; A, B
PRINT "Die Summe der zwei Zahlen ist: "; A+B
----

Beispiel:

[source]
----
Bitte gib zwei Zahlen ein, getrennt durch ein Komma: ? 10,20
Die Summe der zwei Zahlen ist: 30
----

Wenn der Fragetext mit einem Komma (`,`) abgeschlossen wird, wird das
Fragezeichen unterdrückt.

[source,basic]
----
INPUT "Bitte gib zwei Zahlen ein, getrennt durch ein Komma: ", A, B
PRINT "Die Summe der zwei Zahlen ist: "; A+B
----

Beispiel:

[source]
----
Bitte gib zwei Zahlen ein, getrennt durch ein Komma: 10,20
Die Summe der zwei Zahlen ist: 30
----

=== Eine persönliche Begrüßung

Im vorherigen Kapitel hast du bereits String-Variablen für Texte kennengelernt.
Auch mit `INPUT` können solche Texte eingegeben werden.

Für den Namen verwenden wir die String-Variable `NAME$`:

[source,basic]
----
INPUT "Wie heisst du"; NAME$
PRINT "Hallo "; NAME$; ", schön, dass du da bist."
----

Beispiel:

[source]
----
Wie heisst du? Manfred
Hallo Manfred, schön, dass du da bist.
----

Das `$` am Ende von `NAME$` zeigt, wie du bereits weißt, dass diese Variable
einen String enthält.

=== Aussagekräftige Namen bei Eingaben

Gerade bei Benutzereingaben sind aussagekräftige Variablennamen hilfreich.

Statt

[source,basic]
----
INPUT A
INPUT B$
----

kannst du zum Beispiel schreiben:

[source,basic]
----
INPUT "Wie alt bist du"; ALTER
INPUT "Wo wohnst du"; WOHNORT$
----

Beispiel:

[source]
----
Wie alt bist du? 60
Wo wohnst du? Heidelberg
----

Schon beim Lesen des Programms ist damit klar, welche Information in einer
Variablen gespeichert wird.
