== Benutzereingaben mit INPUT

image::bilder/04_benutzereingaben_mit_input.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* wie Daten vom Benutzer eingegeben werden
* wie die Anweisung INPUT verwendet wird
* wie Eingaben in Variablen gespeichert werden
* wie Eingaben weiterverarbeitet werden

Am Ende des Kapitels kannst du eigene interaktive Programme schreiben.

=== Warum Benutzereingaben wichtig sind

Bisher standen alle Werte fest im Programm.

Zum Beispiel:

[source,basic]
----
A=10
B=20
PRINT A+B
----

Das Ergebnis ist immer gleich.

Interessanter wird es, wenn der Benutzer die Werte selbst eingeben kann.

=== Unsere erste Eingabe

Die Anweisung `INPUT` wartet auf eine Eingabe des Benutzers.

Gib folgendes ein:

[source,basic]
----
INPUT A
PRINT A
----

MMBasic zeigt ein Fragezeichen an:

[source]
----
?
----

Gib nun beispielsweise folgende Zahl ein:

[source]
----
42
----

Danach erscheint:

[source]
----
42
----

=== Eingaben in Variablen speichern

Die eingegebene Zahl wird in der Variablen gespeichert.

[source,basic]
----
INPUT A
PRINT A
----

Wenn du 100 eingibst:

[source]
----
100
----

wird dieser Wert in der Variablen `A` gespeichert.

=== Mit Eingaben rechnen

Eingegebene Werte können sofort weiterverarbeitet werden.

[source,basic]
----
INPUT A
PRINT A*2
----

Beispiel:

[source]
----
? 21
42
----

=== Zwei Werte eingeben

Natürlich können auch mehrere Werte eingegeben werden.

[source,basic]
----
INPUT A, B

PRINT A+B
----

Beispiel:

[source]
----
? 10, 20
30
----

Da ein Benutzer nicht erkennen kann, in welcher Form die Eingabe nach dem ? Prompt anzugeben ist, kann dem INPUT Befehl auch ein Fragetext mitgegeben werden. Die Syntax ist dabei:

[source]
----
INPUT ["prompt$(;|,)] var1 [, var2[, var3[, etc]]]
----

Normalerweise wird der Fragetext mit dem Semicolon (;) abgeschlossen. In diesem Fall wird hinter dem Fragetext ein Fragezeichen angezeigt. 

[source,basic]
----
INPUT "Bitte gebe zwei Zahlen ein, getrennt durch ein Komma: "; A, B
PRINT "Die Summe der zwei Zahlen ist: "; A+B
----

Beispiel:

[source]
----
Bitte gebe zwei Zahlen ein, getrennt durch ein Komma: ? 10,20
Die Summe der zwei Zahlen ist: 30
----

Wenn der Fragetext mit einem Komma (,) abgeschlossen wird, wird das Fragezeichen unterdrückt.

[source,basic]
----
INPUT "Bitte gebe zwei Zahlen ein, getrennt durch ein Komma: ", A, B
PRINT "Die Summe der zwei Zahlen ist: "; A+B
----

Beispiel:

[source]
----
Bitte gebe zwei Zahlen ein, getrennt durch ein Komma: 10,20
Die Summe der zwei Zahlen ist: 30
----

=== Eine persönliche Begrüßung

MMBasic kann auch Texte verarbeiten.

Dazu verwenden wir eine String-Variable.

String-Variablen erkennt man am Dollarzeichen am Ende des Namens.

[source,basic]
----
INPUT "Wie heisst du";N$
PRINT "Hallo ";N$;", schön, dass du da bist."
----

Beispiel:

[source]
----
Wie heisst du? Manfred
Hallo Manfred, schön, dass du da bist.
----

[NOTE]
====
MMBasic erlaubt aussagekräftige Variablennamen.

Statt kurzer Namen wie

[source,basic]
----
A
B
X
----

können auch längere Namen verwendet werden:

[source,basic]
----
ALTER
NAME$
WOHNORT$
PUNKTE
----

Ein Variablenname darf mit einem Buchstaben beginnen und kann anschließend weitere Buchstaben, Ziffern und den Unterstrich `_` enthalten.

Für Textvariablen wird häufig ein Dollarzeichen `$` am Ende des Namens verwendet:

[source,basic]
----
NAME$
WOHNORT$
TEXT$
----
====

=== Experimentiere!

Probiere folgende Änderungen aus:

* Gib dein Alter ein.
* Addiere zwei eingegebene Zahlen.
* Gib deinen Wohnort ein.
* Erweitere die Begrüßung um weitere Texte.

=== Probier's selbst!

Versuche folgende Aufgaben:

. Frage den Benutzer nach seinem Namen.
. Frage den Benutzer nach seinem Alter.
. Addiere zwei eingegebene Zahlen.
. Gib eine persönliche Begrüßung aus.
