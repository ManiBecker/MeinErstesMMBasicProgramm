== Die verschiedenen Grafikmodi

image::bilder/17_grafikmodi.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* wie MMBasic Grafiken auf dem Bildschirm darstellt
* was Pixel sind
* wie Bildschirmkoordinaten funktionieren
* wie die Bildschirmgröße ermittelt werden kann
* wie Texte mit `PRINT @()` pixelgenau positioniert werden können
* wie Textpositionen abhängig von Bildschirm- und Textgröße berechnet werden
* wie der Grafikmodus festgelegt wird
* welche Informationen MMBasic über den Bildschirm bereitstellt

Am Ende des Kapitels verstehst du die wichtigsten Grundlagen für die
Grafikprogrammierung und kannst Bildschirmausgaben unabhängig von festen
Koordinaten positionieren.

=== Eine neue Welt

Bisher haben wir unsere Programme hauptsächlich mit Texten erstellt.

Beispielsweise:

[source,basic]
----
PRINT "Hallo Welt"
----

oder:

[source,basic]
----
INPUT NAME$
----

Der Bildschirm wurde dabei wie ein klassisches Terminal verwendet.

MMBasic kann jedoch deutlich mehr.

Mit wenigen Befehlen lassen sich:

* Linien zeichnen
* Kreise darstellen
* Texte frei positionieren
* Farben verwenden
* grafische Benutzeroberflächen erstellen

Bevor wir damit beginnen, sollten wir einige Grundlagen kennenlernen.

=== Was ist ein Pixel?

Jeder Bildschirm besteht aus vielen einzelnen Bildpunkten.

Diese Bildpunkte nennt man indexterm:[Grafik,Pixel]indexterm:[Pixel] Pixel.

Jeder Pixel besitzt eine Position auf dem Bildschirm.

Die Position wird durch zwei Werte beschrieben:

* X = horizontale Position
* Y = vertikale Position

=== Das Koordinatensystem

Das indexterm:[Grafik,Koordinatensystem]indexterm:[Koordinatensystem] Koordinatensystem von MMBasic hat seinen Ursprung in der linken oberen Ecke.

Die Position links oben besitzt die Koordinaten:

[source]
----
X = 0
Y = 0
----

Die X-Koordinate wächst nach rechts.

Die Y-Koordinate wächst nach unten.

[source]
----
(0,0)
  +---------------------------->
  |
  |
  |
  |
  v
----
    
Wenn später eine Linie oder ein Kreis gezeichnet wird, erfolgt dies immer anhand dieser Koordinaten.

=== Die Bildschirmgröße

Je nach verwendetem PicoMite-System stehen unterschiedliche indexterm:[Grafik,Bildschirmauflösung]indexterm:[Bildschirmauflösung] Bildschirmauflösungen zur Verfügung. Bei PicoMite-Systemen mit HDMI- oder VGA-Ausgabe wird die gewünschte Auflösung mit dem Befehl indexterm:[Bildschirmauflösung] `OPTION RESOLUTION` festgelegt.

[source,basic]
----
OPTION RESOLUTION 800
----

Je nach Hardware werden unter anderem folgende Bildschirmauflösungen unterstützt:

[cols="2,3",options="header"]
|===
|Auflösung |Bemerkung

|640 x 480
|Standardauflösung für HDMI und VGA

|720 x 400
|Alternative Bildschirmauflösung

|800 x 600
|Nur auf RP2350-Systemen verfügbar

|848 x 480
|Nur auf RP2350-Systemen verfügbar

|1024 x 768
|Nur HDMI

|1280 x 720
|Nur HDMI (HD-Auflösung)
|===

Eine höhere Bildschirmauflösung bietet mehr Platz für Grafiken und Texte. Gleichzeitig steigt jedoch auch der Speicherbedarf der Grafikausgabe. Dadurch stehen einem MMBasic-Programm weniger Programm- und Variablenspeicher zur Verfügung.

Welche Bildschirmauflösung aktuell am System eingestellt ist, kann anhand zweier Variablen ermittelt werden, die MMBasic bereitstellt: indexterm:[Systemvariablen,MM.HRES]indexterm:[MM.HRES] `MM.HRES` und indexterm:[Systemvariablen,MM.VRES]indexterm:[MM.VRES] `MM.VRES`.

[source,basic]
----
PRINT MM.HRES
PRINT MM.VRES
----

Beispiel:

[source]
----
640
480
----

Dies bedeutet:

* 640 Pixel Breite
* 480 Pixel Höhe

Die Variablen haben folgende Bedeutung:

[cols="1,3"]
|===
|Variable |Beschreibung

|MM.HRES
|Horizontale Auflösung (Breite)

|MM.VRES
|Vertikale Auflösung (Höhe)
|===

Die Bildschirmauflösung bestimmt also die Größe des Zeichenbereichs. Wie dieser Zeichenbereich anschließend von MMBasic genutzt wird, legen wir im nächsten Abschnitt mit dem Befehl `MODE` fest.

[IMPORTANT]
====
`OPTION RESOLUTION` und `MODE` erfüllen unterschiedliche Aufgaben.

Mit `OPTION RESOLUTION` wird die grundlegende Ausgabeauflösung des VGA- oder
HDMI-Systems festgelegt.

Mit `MODE` wählen wir anschließend aus, wie MMBasic diese Bildschirmausgabe
für Grafik und Farben verwendet.

Deshalb kann sich die mit `MM.HRES` und `MM.VRES` gemeldete Größe des
Zeichenbereichs beim Wechsel des Grafikmodus ändern.
====

=== Der Grafikmodus

Bevor wir Grafiken zeichnen können, muss zunächst ein geeigneter Grafikmodus ausgewählt werden.

Dies geschieht mit dem Befehl indexterm:[Grafikbefehle,MODE]indexterm:[MODE] `MODE`.

[source,basic]
----
MODE 2
----

Der Grafikmodus legt fest, wie der Bildschirm verwendet wird. Dazu gehören unter anderem:

* die Bildschirmauflösung
* die Anzahl der darstellbaren Farben
* die verfügbare Bildschirmfläche
* die Größe der Schrift

Welche Grafikmodi verfügbar sind, hängt von der verwendeten Hardware ab.
Ein PicoMite mit HDMI-Ausgabe bietet beispielsweise andere Grafikmodi als ein PicoMite mit VGA-Ausgabe oder ein Colour Maximite 2.

Die meisten Grafikprogramme in diesem Tutorial verwenden `MODE 2`. Dieser Modus eignet sich besonders gut für die gezeigten Beispiele und steht auf den meisten PicoMite-Systemen zur Verfügung.

Die folgende Tabelle gibt einen Überblick über typische Grafikmodi.
Nicht jeder Modus steht mit jeder PicoMite-Firmware, Ausgabeart und
eingestellten Bildschirmauflösung zur Verfügung.

[cols="1,2,2,4",options="header"]
|===
|MODE |Auflösung |Farben |Verwendung

|1
|640 x 480
|2
|Monochrome Darstellung, Standardmodus nach dem Einschalten

|2
|320 x 240
|16
|Einfacher Farbmodus, ideal für erste Grafikprogramme

|3
|640 x 480
|16
|Höhere Auflösung bei 16 Farben

|4
|320 x 240
|32.768
|RGB555-Farbmodus für hochwertige Farbgrafiken

|5
|320 x 240
|256
|256 Farben mit frei belegbarer Farbpalette
|===

=== Bildschirminformationen anzeigen

Mit dem folgenden Programm kann die aktuelle Bildschirmgröße beim Grafikmodus MODE 2 ausgegeben werden.

[source,basic]
----
MODE 2

PRINT "Bildschirminformationen"
PRINT

PRINT "Breite : ";MM.HRES
PRINT "Hoehe  : ";MM.VRES
----

=== Schriftarten

MMBasic besitzt mehrere eingebaute Schriftarten.

Je nach Schriftart unterscheiden sich Breite und Höhe der Zeichen.

Die aktuelle Schriftgröße kann mit indexterm:[MM.INFO(FONTWIDTH)] `MM.INFO(FONTWIDTH)` und indexterm:[MM.INFO(FONTHEIGHT)] `MM.INFO(FONTHEIGHT)` abgefragt werden.

[source,basic]
----
PRINT MM.INFO(FONTWIDTH)
PRINT MM.INFO(FONTHEIGHT)
----

Beispiel:

[source]
----
8
12
----

Das bedeutet:

* 8 Pixel breit
* 12 Pixel hoch

=== Warum ist das wichtig?

Wenn Texte an einer bestimmten Position ausgegeben werden sollen, muss bekannt sein, wie groß die verwendete Schrift ist.

Dadurch können Texte exakt positioniert werden.

=== Text pixelgenau positionieren

Bisher haben wir `PRINT` verwendet, um Texte an der aktuellen Schreibposition auszugeben. MMBasic bietet jedoch auch die Möglichkeit, die Ausgabe von `PRINT` direkt an einer bestimmten Pixelposition zu beginnen.

Dazu wird hinter `PRINT` die Funktion indexterm:[PRINT @()] `@()` angegeben:

[source,basic]
----
PRINT @(x,y) Ausdruck
----

`x` und `y` sind dabei die Pixelkoordinaten auf dem Bildschirm.

Ein Beispiel:

[source,basic]
----
MODE 1
CLS

PRINT @(50,50) "Hallo MMBasic!"
PRINT @(100,100) "X=100, Y=100"
PRINT @(200,200) "X=200, Y=200"
----

Die Texte beginnen jeweils an den angegebenen Pixelkoordinaten. Damit können wir das zuvor kennengelernte Koordinatensystem auch für die Textausgabe verwenden.

Wird die Y-Koordinate weggelassen, ändert `@()` nur die horizontale Position. Die aktuelle Zeile bleibt erhalten.

[source,basic]
----
PRINT @(100) "Dieser Text beginnt bei X=100"
----

Die Funktion `@()` kann innerhalb einer `PRINT`-Anweisung auch mehrfach verwendet werden.

[source,basic]
----
PRINT @(50,50) "Hallo" @(50,80) "MMBasic"
----

Dadurch lassen sich mehrere Texte mit einer einzigen `PRINT`-Anweisung an unterschiedlichen Positionen ausgeben.

==== Verschiedene Ausgabemodi

`@()` kann zusätzlich einen dritten Parameter erhalten:

[source,basic]
----
PRINT @(x,y,m) Ausdruck
----

Der Wert `m` bestimmt, wie der Text ausgegeben wird.

[cols="1,4",options="header"]
|===
|m |Ausgabe

|0
|Normale Textausgabe mit Hintergrund

|1
|Der Hintergrund wird nicht gezeichnet und bleibt transparent

|2
|Invertierte Textausgabe

|5
|Die vorhandenen Pixel werden invertiert, der Hintergrund bleibt transparent
|===

Beispiel:

[source,basic]
----
PRINT @(50,50,0) "Normal"
PRINT @(50,80,1) "Transparent"
PRINT @(50,110,2) "Invertiert"
PRINT @(50,140,5) "Pixel invertieren"
----

`PRINT @()` funktioniert sowohl auf der Terminal-Konsole eines angeschlossenen Computers als auch bei VGA- oder HDMI-Ausgabe. Bei einem LCD-Display kann es verwendet werden, wenn das Display mit `OPTION LCDPANEL CONSOLE` als Konsole eingerichtet wurde.

[NOTE]
====
Später lernen wir mit `TEXT` noch einen speziellen Grafikbefehl für Texte kennen. Dieser bietet zusätzliche Möglichkeiten wie Ausrichtung, Skalierung, Farbe und Drehung. Für eine einfache pixelgenaue Textausgabe ist `PRINT @()` jedoch sehr praktisch.
====

=== Verschiedene Ausgabegeräte

MMBasic unterstützt verschiedene Grafiksysteme.

Dazu gehören:

* LCD-Displays
* VGA-Monitore
* HDMI-Monitore

Je nach verwendeter Hardware unterscheiden sich:

* Auflösung
* Farbtiefe
* verfügbare Grafikmodi

Die Grafikbefehle selbst funktionieren jedoch weitgehend identisch.

=== Farben

Farben werden in MMBasic mit der Funktion indexterm:[Grafikfunktionen,RGB()]indexterm:[RGB()] `RGB()` beschrieben.

Beispiele:

[source,basic]
----
RGB(RED)
RGB(BLUE)
RGB(GREEN)
RGB(YELLOW)
----

Oder mit numerischen Farbwerten:

[source,basic]
----
RGB(255,0,0)
RGB(0,255,0)
RGB(0,0,255)
----

Die genaue Verwendung von Farben werden wir im nächsten Kapitel kennenlernen.

=== Ein erstes Informationsprogramm

Das folgende Programm zeigt einige wichtige Informationen über den aktuell verwendeten Bildschirm an.

[source,basic]
----
MODE 2
PRINT "Grafiksystem"
PRINT "------------"
PRINT
PRINT "Breite      : ";MM.HRES
PRINT "Hoehe       : ";MM.VRES
PRINT
PRINT "Fontbreite  : ";MM.INFO(FONTWIDTH)
PRINT "Fonthoehe   : ";MM.INFO(FONTHEIGHT)
----

Eine mögliche Ausgabe könnte so aussehen:

[source]
----
Grafiksystem
------------

Breite      : 320
Hoehe       : 240

Fontbreite  : 6
Fonthoehe   : 8
----

=== Praxisbeispiel: Text automatisch zentrieren

Wir kennen nun die Größe unseres Grafikbereichs und wissen, wie Texte mit
`PRINT @(x,y)` an einer bestimmten Bildschirmposition ausgegeben werden.

Damit können wir eine kleine Aufgabe lösen, die in vielen Programmen benötigt
wird: Wir möchten einen Text genau in der Mitte des Bildschirms ausgeben.

Eine feste Position wie

[source,basic]
----
PRINT @(200,100) "MMBasic"
----

funktioniert zwar, ist aber nur für eine bestimmte Bildschirmauflösung und
einen bestimmten Text geeignet.

Ändert sich die Auflösung oder die Länge des Textes, stimmt die Position nicht
mehr.

Besser ist es, die Position vom Programm berechnen zu lassen.

==== Die Bildschirmmitte berechnen

Die Breite des aktuellen Grafikbereichs erhalten wir mit `MM.HRES`, die Höhe
mit `MM.VRES`.

Die Mitte des Bildschirms liegt deshalb zunächst bei:

[source,basic]
----
X=MM.HRES\2
Y=MM.VRES\2
----

Wenn wir den Text einfach an dieser Position ausgeben,

[source,basic]
----
PRINT @(X,Y) "MMBasic"
----

beginnt der Text allerdings erst in der Bildschirmmitte. Er ist also nicht
wirklich zentriert.

Das liegt daran, dass `PRINT @(x,y)` die Position der linken oberen Ecke des
Textes angibt.

==== Die Größe des Textes berücksichtigen

Um den Text wirklich zu zentrieren, müssen wir seine Breite kennen.

Mit

[source,basic]
----
MM.INFO(FONTWIDTH)
----

erhalten wir die Breite eines Zeichens des aktuell verwendeten Fonts in
Pixeln.

Die Anzahl der Zeichen eines Textes kennen wir bereits aus Kapitel 12:
`LEN()` liefert die Länge einer Zeichenkette.

Damit können wir die Breite unseres Textes berechnen:

[source,basic]
----
BREITE=LEN(TEXT$)*MM.INFO(FONTWIDTH)
----

Für die horizontale Position ziehen wir diese Breite zunächst von der
Bildschirmbreite ab und teilen das Ergebnis durch zwei:

[source,basic]
----
X=(MM.HRES-BREITE)\2
----

Für die vertikale Position benötigen wir entsprechend die Höhe des aktuellen
Fonts:

[source,basic]
----
Y=(MM.VRES-MM.INFO(FONTHEIGHT))\2
----

Nun können wir den Text an der berechneten Position ausgeben:

[source,basic]
----
PRINT @(X,Y) TEXT$
----

Der Text erscheint damit unabhängig von seiner Länge genau in der Mitte des
Grafikbereichs.

==== Das vollständige Programm

Unser kleines Beispiel benötigt nur wenige Zeilen:

[source,basic]
----
CLS

TEXT$="Mein erstes MMBasic Programm"

BREITE=LEN(TEXT$)*MM.INFO(FONTWIDTH)

X=(MM.HRES-BREITE)\2
Y=(MM.VRES-MM.INFO(FONTHEIGHT))\2

PRINT @(X,Y) TEXT$
----

Ändere nun den Inhalt von `TEXT$`:

[source,basic]
----
TEXT$="MMBasic"
----

oder beispielsweise:

[source,basic]
----
TEXT$="Hallo PicoMite!"
----

Obwohl die Texte unterschiedlich lang sind, berechnet das Programm jedes Mal
eine neue Position und gibt den Text wieder zentriert aus.

[TIP]
====
Versuche nicht, die passenden Koordinaten durch Ausprobieren zu finden.

Wenn die benötigte Position aus bekannten Größen berechnet werden kann, ist
das Programm flexibler und funktioniert auch mit anderen Texten oder
Bildschirmgrößen.
====

==== Was haben wir dabei verwendet?

Dieses kleine Beispiel verbindet gleich mehrere Dinge, die wir bereits
kennengelernt haben:

* `MM.HRES` liefert die Breite des Grafikbereichs.
* `MM.VRES` liefert die Höhe des Grafikbereichs.
* `MM.INFO(FONTWIDTH)` liefert die Breite eines Zeichens.
* `MM.INFO(FONTHEIGHT)` liefert die Höhe eines Zeichens.
* `LEN()` bestimmt die Anzahl der Zeichen unseres Textes.
* `PRINT @(x,y)` gibt den Text an der berechneten Position aus.

Damit haben wir zum ersten Mal die Eigenschaften des aktuellen Grafikmodus
verwendet, um die Position einer Ausgabe automatisch zu berechnen.

Im nächsten Schritt können wir dasselbe Prinzip auf echte Grafikelemente
anwenden: Punkte, Linien, Rechtecke und andere Formen lassen sich ebenfalls
über ihre Koordinaten gezielt auf dem Bildschirm positionieren.

=== Experimentiere!

Probiere folgende Änderungen aus:

* Führe das Programm auf verschiedenen Geräten aus.
* Vergleiche HDMI und VGA.
* Ändere die Schriftart und beobachte die Werte.
* Notiere die Bildschirmgröße deines Systems.
* Positioniere einen Text genau in der Bildschirmmitte.
* Gib Texte in allen vier Bildschirmecken aus.
* Ändere den Grafikmodus und beobachte, wie sich `MM.HRES` und `MM.VRES` verändern.
* Berechne die Position so, dass ein Text unabhängig von seiner Länge zentriert erscheint.

Versuche folgende Aufgaben:

=== Zusammenfassung

In diesem Kapitel hast du die Grundlagen der Grafikprogrammierung kennengelernt.

Du weißt nun:

* was Pixel sind
* wie das Koordinatensystem funktioniert
* wie die Bildschirmgröße bestimmt wird
* wie Schriftgrößen abgefragt werden können
* wie Texte mit `PRINT @()` pixelgenau positioniert werden können
* wie Textpositionen aus Bildschirmgröße, Schriftgröße und Textlänge berechnet werden
* wie der Grafikmodus festgelegt wird
* wie Farben beschrieben werden

Im Praxisbeispiel hast du diese Informationen miteinander kombiniert und
einen Text unabhängig von seiner Länge automatisch in der Bildschirmmitte
positioniert.

Damit kennst du die wichtigsten Grundlagen, um grafische Ausgaben nicht nur
an festen Koordinaten, sondern abhängig von der aktuellen Bildschirmgröße zu
positionieren.

Im nächsten Kapitel beschäftigen wir uns ausführlicher mit Farben und lernen
außerdem die verschiedenen Schriftarten von MMBasic kennen.
