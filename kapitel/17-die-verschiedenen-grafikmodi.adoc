== Die verschiedenen Grafikmodi

image::bilder/17_grafikmodi.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* wie MMBasic Grafiken auf dem Bildschirm darstellt
* was Pixel sind
* wie Bildschirmkoordinaten funktionieren
* wie die Bildschirmgröße ermittelt werden kann
* wie Texte mit `PRINT @()` pixelgenau positioniert werden können
* wie der Grafikmodus festgelegt wird
* welche Informationen MMBasic über den Bildschirm bereitstellt

Am Ende des Kapitels verstehst du die wichtigsten Grundlagen für die Grafikprogrammierung.

=== Eine neue Welt

Bisher haben wir unsere Programme hauptsächlich mit Texten erstellt.

Beispielsweise:

[source,basic]
----
PRINT "Hallo Welt"
----

oder:

[source,basic]
----
INPUT NAME$
----

Der Bildschirm wurde dabei wie ein klassisches Terminal verwendet.

MMBasic kann jedoch deutlich mehr.

Mit wenigen Befehlen lassen sich:

* Linien zeichnen
* Kreise darstellen
* Texte frei positionieren
* Farben verwenden
* grafische Benutzeroberflächen erstellen

Bevor wir damit beginnen, sollten wir einige Grundlagen kennenlernen.

=== Was ist ein Pixel?

Jeder Bildschirm besteht aus vielen einzelnen Bildpunkten.

Diese Bildpunkte nennt man Pixel.

Jeder Pixel besitzt eine Position auf dem Bildschirm.

Die Position wird durch zwei Werte beschrieben:

* X = horizontale Position
* Y = vertikale Position

=== Das Koordinatensystem

In MMBasic befindet sich der Ursprung in der linken oberen Ecke.

Die Position links oben besitzt die Koordinaten:

[source]
----
X = 0
Y = 0
----

Die X-Koordinate wächst nach rechts.

Die Y-Koordinate wächst nach unten.

[source]
----
(0,0)
  +---------------------------->
  |
  |
  |
  |
  v
----
    
Wenn später eine Linie oder ein Kreis gezeichnet wird, erfolgt dies immer anhand dieser Koordinaten.

=== Die Bildschirmgröße

Je nach verwendetem PicoMite-System stehen unterschiedliche Bildschirmauflösungen zur Verfügung. Bei PicoMite-Systemen mit HDMI- oder VGA-Ausgabe wird die gewünschte Auflösung mit dem Befehl `OPTION RESOLUTION` festgelegt.

[source,basic]
----
OPTION RESOLUTION 800
----

Je nach Hardware werden unter anderem folgende Bildschirmauflösungen unterstützt:

[cols="2,3",options="header"]
|===
|Auflösung |Bemerkung

|640 x 480
|Standardauflösung für HDMI und VGA

|720 x 400
|Alternative Bildschirmauflösung

|800 x 600
|Nur auf RP2350-Systemen verfügbar

|848 x 480
|Nur auf RP2350-Systemen verfügbar

|1024 x 768
|Nur HDMI

|1280 x 720
|Nur HDMI (HD-Auflösung)
|===

Eine höhere Bildschirmauflösung bietet mehr Platz für Grafiken und Texte. Gleichzeitig steigt jedoch auch der Speicherbedarf der Grafikausgabe. Dadurch stehen einem MMBasic-Programm weniger Programm- und Variablenspeicher zur Verfügung.

Welche Bildschirmauflösungen aktuell am System eingestellt ist, kann anhand zweier Variable ermittelt werden, die MMBasic bereitstellt.

[source,basic]
----
PRINT MM.HRES
PRINT MM.VRES
----

Beispiel:

[source]
----
640
480
----

Dies bedeutet:

* 640 Pixel Breite
* 480 Pixel Höhe

Die Variablen haben folgende Bedeutung:

[cols="1,3"]
|===
|Variable |Beschreibung

|MM.HRES
|Horizontale Auflösung (Breite)

|MM.VRES
|Vertikale Auflösung (Höhe)
|===

Die Bildschirmauflösung bestimmt also die Größe des Zeichenbereichs. Wie dieser Zeichenbereich anschließend von MMBasic genutzt wird, legen wir im nächsten Abschnitt mit dem Befehl `MODE` fest.

=== Der Grafikmodus

Bevor wir Grafiken zeichnen können, muss zunächst ein geeigneter Grafikmodus ausgewählt werden.

Dies geschieht mit dem Befehl `MODE`.

[source,basic]
----
MODE 2
----

Der Grafikmodus legt fest, wie der Bildschirm verwendet wird. Dazu gehören unter anderem:

* die Bildschirmauflösung
* die Anzahl der darstellbaren Farben
* die verfügbare Bildschirmfläche
* die Größe der Schrift

Welche Grafikmodi verfügbar sind, hängt von der verwendeten Hardware ab.
Ein PicoMite mit HDMI-Ausgabe bietet beispielsweise andere Grafikmodi als ein PicoMite mit VGA-Ausgabe oder ein Colour Maximite 2.

Die meisten Grafikprogramme in diesem Tutorial verwenden `MODE 2`. Dieser Modus eignet sich besonders gut für die gezeigten Beispiele und steht auf den meisten PicoMite-Systemen zur Verfügung.

[cols="1,2,2,4",options="header"]
|===
|MODE |Auflösung |Farben |Verwendung

|1
|640 x 480
|2
|Monochrome Darstellung, Standardmodus nach dem Einschalten

|2
|320 x 240
|16
|Einfacher Farbmodus, ideal für erste Grafikprogramme

|3
|640 x 480
|16
|Höhere Auflösung bei 16 Farben

|4
|320 x 240
|32.768
|RGB555-Farbmodus für hochwertige Farbgrafiken

|5
|320 x 240
|256
|256 Farben mit frei belegbarer Farbpalette
|===

=== Bildschirminformationen anzeigen

Mit dem folgenden Programm kann die aktuelle Bildschirmgröße beim Grafikmodus MODE 2 ausgegeben werden.

[source,basic]
----
MODE 2

PRINT "Bildschirminformationen"
PRINT

PRINT "Breite : ";MM.HRES
PRINT "Hoehe  : ";MM.VRES
----

=== Schriftarten

MMBasic besitzt mehrere eingebaute Schriftarten.

Je nach Schriftart unterscheiden sich Breite und Höhe der Zeichen.

Die aktuelle Schriftgröße kann abgefragt werden.

[source,basic]
----
PRINT MM.INFO(FONTWIDTH)
PRINT MM.INFO(FONTHEIGHT)
----

Beispiel:

[source]
----
8
12
----

Das bedeutet:

* 8 Pixel breit
* 12 Pixel hoch

=== Warum ist das wichtig?

Wenn Texte an einer bestimmten Position ausgegeben werden sollen, muss bekannt sein, wie groß die verwendete Schrift ist.

Dadurch können Texte exakt positioniert werden.

=== Text pixelgenau positionieren

Bisher haben wir `PRINT` verwendet, um Texte an der aktuellen Schreibposition auszugeben. MMBasic bietet jedoch auch die Möglichkeit, die Ausgabe von `PRINT` direkt an einer bestimmten Pixelposition zu beginnen.

Dazu wird hinter `PRINT` die Funktion `@()` angegeben:

[source,basic]
----
PRINT @(x,y) Ausdruck
----

`x` und `y` sind dabei die Pixelkoordinaten auf dem Bildschirm.

Ein Beispiel:

[source,basic]
----
MODE 1
CLS

PRINT @(50,50) "Hallo MMBasic!"
PRINT @(100,100) "X=100, Y=100"
PRINT @(200,200) "X=200, Y=200"
----

Die Texte beginnen jeweils an den angegebenen Pixelkoordinaten. Damit können wir das zuvor kennengelernte Koordinatensystem auch für die Textausgabe verwenden.

Wird die Y-Koordinate weggelassen, ändert `@()` nur die horizontale Position. Die aktuelle Zeile bleibt erhalten.

[source,basic]
----
PRINT @(100) "Dieser Text beginnt bei X=100"
----

Die Funktion `@()` kann innerhalb einer `PRINT`-Anweisung auch mehrfach verwendet werden.

[source,basic]
----
PRINT @(50,50) "Hallo" @(50,80) "MMBasic"
----

Dadurch lassen sich mehrere Texte mit einer einzigen `PRINT`-Anweisung an unterschiedlichen Positionen ausgeben.

==== Verschiedene Ausgabemodi

`@()` kann zusätzlich einen dritten Parameter erhalten:

[source,basic]
----
PRINT @(x,y,m) Ausdruck
----

Der Wert `m` bestimmt, wie der Text ausgegeben wird.

[cols="1,4",options="header"]
|===
|m |Ausgabe

|0
|Normale Textausgabe mit Hintergrund

|1
|Der Hintergrund wird nicht gezeichnet und bleibt transparent

|2
|Invertierte Textausgabe

|5
|Die vorhandenen Pixel werden invertiert, der Hintergrund bleibt transparent
|===

Beispiel:

[source,basic]
----
PRINT @(50,50,0) "Normal"
PRINT @(50,80,1) "Transparent"
PRINT @(50,110,2) "Invertiert"
PRINT @(50,140,5) "Pixel invertieren"
----

`PRINT @()` funktioniert sowohl auf der Terminal-Konsole eines angeschlossenen Computers als auch bei VGA- oder HDMI-Ausgabe. Bei einem LCD-Display kann es verwendet werden, wenn das Display mit `OPTION LCDPANEL CONSOLE` als Konsole eingerichtet wurde.

[NOTE]
====
Später lernen wir mit `TEXT` noch einen speziellen Grafikbefehl für Texte kennen. Dieser bietet zusätzliche Möglichkeiten wie Ausrichtung, Skalierung, Farbe und Drehung. Für eine einfache pixelgenaue Textausgabe ist `PRINT @()` jedoch sehr praktisch.
====

=== Verschiedene Ausgabegeräte

MMBasic unterstützt verschiedene Grafiksysteme.

Dazu gehören:

* LCD-Displays
* VGA-Monitore
* HDMI-Monitore

Je nach verwendeter Hardware unterscheiden sich:

* Auflösung
* Farbtiefe
* verfügbare Grafikmodi

Die Grafikbefehle selbst funktionieren jedoch weitgehend identisch.

=== Farben

Farben werden in MMBasic mit der Funktion RGB() beschrieben.

Beispiele:

[source,basic]
----
RGB(RED)
RGB(BLUE)
RGB(GREEN)
RGB(YELLOW)
----

Oder mit numerischen Farbwerten:

[source,basic]
----
RGB(255,0,0)
RGB(0,255,0)
RGB(0,0,255)
----

Die genaue Verwendung von Farben werden wir im nächsten Kapitel kennenlernen.

=== Ein erstes Informationsprogramm

Das folgende Programm zeigt einige wichtige Informationen über den aktuell verwendeten Bildschirm an.

[source,basic]
----
MODE 2
PRINT "Grafiksystem"
PRINT "------------"
PRINT
PRINT "Breite      : ";MM.HRES
PRINT "Hoehe       : ";MM.VRES
PRINT
PRINT "Fontbreite  : ";MM.INFO(FONTWIDTH)
PRINT "Fonthoehe   : ";MM.INFO(FONTHEIGHT)
----

Eine mögliche Ausgabe könnte so aussehen:

[source]
----
Grafiksystem
------------

Breite      : 320
Hoehe       : 240

Fontbreite  : 6
Fonthoehe   : 8
----

=== Experimentiere!

Probiere folgende Änderungen aus:

* Führe das Programm auf verschiedenen Geräten aus.
* Vergleiche HDMI und VGA.
* Ändere die Schriftart und beobachte die Werte.
* Notiere die Bildschirmgröße deines Systems.

=== Probier's selbst!

Versuche folgende Aufgaben:

. Gib die Bildschirmbreite aus.
. Gib die Bildschirmhöhe aus.
. Gib die Fontbreite aus.
. Gib die Fonthöhe aus.
. Berechne die Bildschirmmitte.
. Gib mit `PRINT @()` einen Text ungefähr in der Bildschirmmitte aus.
