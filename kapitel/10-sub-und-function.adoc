== Programme strukturieren mit SUB und FUNCTION

image::bilder/10_sub_und_function.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* Programme in kleinere Bausteine aufzuteilen
* eigene Unterprogramme mit `SUB` zu erstellen
* eigene Funktionen mit `FUNCTION` zu schreiben
* Parameter an Unterprogramme und Funktionen zu übergeben
* Werte aus Funktionen zurückzugeben
* wiederkehrende Aufgaben in Unterprogrammen zusammenzufassen
* Berechnungen in eigenen Funktionen zu kapseln
* `SUB` und `FUNCTION` gemeinsam in einem Programm zu verwenden

Am Ende des Kapitels kannst du eigene Befehle und Funktionen entwickeln.

=== Warum Programme strukturieren?

Unsere Programme werden langsam größer.

Das Zahlenratespiel aus dem letzten Kapitel besteht bereits aus vielen Zeilen Code.

Bei größeren Programmen wird es zunehmend schwieriger, den Überblick zu behalten.

Deshalb teilen Programmierer ihre Programme in kleinere, überschaubare Bausteine auf.

MMBasic stellt dafür SUB und FUNCTION zur Verfügung.

=== Unsere erste SUB

Eine indexterm:[SUB] `SUB` fasst mehrere Anweisungen zu einem indexterm:[SUB] Unterprogramm zusammen.

[source,basic]
----
SUB Begruessung

  PRINT "Hallo Welt!"

END SUB

Begruessung
----

Ausgabe:

[source]
----
Hallo Welt!
----

Die Anweisungen zwischen `SUB` und indexterm:[END SUB] `END SUB` werden erst ausgeführt, wenn die `SUB` aufgerufen wird.

=== Eine SUB mehrfach aufrufen

Eine SUB kann beliebig oft verwendet werden.

[source,basic]
----
SUB Begruessung

  PRINT "Hallo Welt!"

END SUB

Begruessung
Begruessung
Begruessung
----

Ausgabe:

[source]
----
Hallo Welt!
Hallo Welt!
Hallo Welt!
----

=== Eine SUB mit Parametern

Oft soll ein Unterprogramm unterschiedliche Werte verarbeiten.

Dazu können indexterm:[Parameter] Parameter verwendet werden.

[source,basic]
----
SUB Begruessung(NAME$)

  PRINT "Hallo ";NAME$

END SUB

Begruessung("Manfred")
Begruessung("Geoff")
Begruessung("Peter")
----

Ausgabe:

[source]
----
Hallo Manfred
Hallo Geoff
Hallo Peter
----

=== Warum FUNCTION?

Eine SUB führt Anweisungen aus.

Manchmal möchten wir jedoch einen Wert berechnen und zurückgeben.

Dafür gibt es indexterm:[FUNCTION] `FUNCTION`.

=== Unsere erste FUNCTION

[source,basic]
----
FUNCTION Quadrat(X)

  Quadrat=X*X

END FUNCTION

PRINT Quadrat(5)
----

Ausgabe:

[source]
----
25
----

Die Funktion wird mit indexterm:[END FUNCTION] `END FUNCTION` abgeschlossen. Sie erhält einen Wert als Parameter und liefert das Quadrat dieses Wertes zurück.

=== Weitere Funktionen

[source,basic]
----
FUNCTION Verdoppeln(X)

  Verdoppeln=X*2

END FUNCTION

PRINT Verdoppeln(10)
----

Ausgabe:

[source]
----
20
----

=== Funktionen in Berechnungen verwenden

Der indexterm:[Rückgabewert] Rückgabewert einer Funktion kann direkt in Berechnungen verwendet werden.

[source,basic]
----
FUNCTION Quadrat(X)

  Quadrat=X*X

END FUNCTION

PRINT Quadrat(5)+Quadrat(3)
----

Ausgabe:

[source]
----
34
----

=== Eine Würfelfunktion

Mit Funktionen lassen sich eigene BASIC-Befehle erstellen.

[source,basic]
----
FUNCTION Wuerfel()

  Wuerfel=INT(RND*6)+1

END FUNCTION

PRINT Wuerfel()
PRINT Wuerfel()
PRINT Wuerfel()
----

Mögliche Ausgabe:

[source]
----
4
1
6
----

Bei jedem Aufruf wird eine neue Zufallszahl erzeugt.

=== Eine mathematische Funktion

Eigene Funktionen eignen sich hervorragend für mathematische Berechnungen.

[source,basic]
----
FUNCTION F(X)

  F=0.5*X^2+X+0.5

END FUNCTION

FOR X=0 TO 10

  PRINT X;"  ";F(X)

NEXT X
----

Die Funktion berechnet dabei: y = 0.5x² + x + 0.5

=== Das Zahlenratespiel verbessern

Im letzten Kapitel wurde die geheime Zahl direkt erzeugt:

[source,basic]
----
GEHEIM=INT(RND*100)+1
----

Mit einer Funktion wird der Programmcode besser lesbar.

[source,basic]
----
FUNCTION NeueZahl()

  NeueZahl=INT(RND*100)+1

END FUNCTION

GEHEIM=NeueZahl()
----

Der Programmierer erkennt sofort, was die Zeile bewirkt.

=== Wann verwendet man SUB?

Eine SUB eignet sich für Programmteile, die Aufgaben ausführen.

Beispiele:

* Begrüßungen ausgeben
* Menüs anzeigen
* Bildschirmausgaben erzeugen
* Daten einlesen

=== Wann verwendet man FUNCTION?

Eine FUNCTION eignet sich für Programmteile, die einen Wert berechnen.

Beispiele:

* Flächen berechnen
* Temperaturen umrechnen
* Zufallszahlen erzeugen
* mathematische Funktionen berechnen

=== Eine SUB für wiederkehrende Aufgaben

Besonders nützlich sind Unterprogramme, wenn dieselbe Aufgabe an mehreren
Stellen eines Programms benötigt wird.

Das folgende Unterprogramm zeichnet eine Trennlinie mit einer frei wählbaren
Länge:

[source,basic]
----
SUB Linie(ANZAHL)

  FOR I=1 TO ANZAHL
    PRINT "-";
  NEXT I
  PRINT

END SUB

PRINT "MMBasic Tutorial"
Linie(20)
PRINT "Kapitel 10"
Linie(20)
----

Ausgabe:

[source]
----
MMBasic Tutorial
--------------------
Kapitel 10
--------------------
----

Wenn wir später das Aussehen der Linie ändern möchten, müssen wir dafür nur
noch die `SUB` ändern.

=== Eine Funktion zur Temperaturumrechnung

Eine Funktion kann eine Berechnung kapseln, die an verschiedenen Stellen
eines Programms benötigt wird.

[source,basic]
----
FUNCTION Fahrenheit(C)

  Fahrenheit=C*9/5+32

END FUNCTION

PRINT "0 Grad Celsius = ";Fahrenheit(0);" Grad Fahrenheit"
PRINT "20 Grad Celsius = ";Fahrenheit(20);" Grad Fahrenheit"
PRINT "30 Grad Celsius = ";Fahrenheit(30);" Grad Fahrenheit"
----

Ausgabe:

[source]
----
0 Grad Celsius = 32 Grad Fahrenheit
20 Grad Celsius = 68 Grad Fahrenheit
30 Grad Celsius = 86 Grad Fahrenheit
----

=== Werte auf einen Bereich begrenzen

In vielen Programmen darf ein Wert einen bestimmten Bereich nicht verlassen.
Dafür können wir eine eigene Funktion schreiben:

[source,basic]
----
FUNCTION Begrenzen(WERT,MINIMUM,MAXIMUM)

  IF WERT<MINIMUM THEN WERT=MINIMUM
  IF WERT>MAXIMUM THEN WERT=MAXIMUM

  Begrenzen=WERT

END FUNCTION

PRINT Begrenzen(120,0,100)
PRINT Begrenzen(50,0,100)
PRINT Begrenzen(-10,0,100)
----

Ausgabe:

[source]
----
100
50
0
----

=== SUB und FUNCTION gemeinsam verwenden

In einem größeren Programm werden Unterprogramme und Funktionen häufig
gemeinsam eingesetzt.

[source,basic]
----
FUNCTION Wuerfel()

  Wuerfel=INT(RND*6)+1

END FUNCTION

SUB WurfAnzeigen(WURF)

  PRINT "Du hast eine ";WURF;" gewuerfelt."

END SUB

FOR I=1 TO 3
  WURF=Wuerfel()
  WurfAnzeigen(WURF)
NEXT I
----

Eine `FUNCTION` erzeugt hier den Würfelwert und gibt ihn zurück.
Die `SUB` übernimmt die Ausgabe.

Dadurch erhält jeder Programmteil eine klar abgegrenzte Aufgabe.

=== Beispiel: Den Body-Mass-Index berechnen

Ein praktisches Beispiel für eine Funktion ist die Berechnung des
indexterm:[Body-Mass-Index] Body-Mass-Index (BMI).

Der BMI wird aus dem Körpergewicht in Kilogramm und der Körpergröße in Metern
berechnet:

----
BMI = Gewicht / (Größe * Größe)
----

Dafür können wir eine eigene Funktion schreiben:

[source,basic]
----
FUNCTION BMI(GEWICHT,GROESSE)

  BMI=GEWICHT/(GROESSE*GROESSE)

END FUNCTION

PRINT BMI(80,1.80)
----

Ausgabe:

[source]
----
24.69136
----

Unsere Funktion erwartet zwei Werte:

* `GEWICHT` ist das Körpergewicht in Kilogramm.
* `GROESSE` ist die Körpergröße in Metern.

Die Funktion berechnet daraus den BMI und gibt das Ergebnis zurück.

Natürlich können die Werte auch vom Benutzer eingegeben werden:

[source,basic]
----
INPUT "Gewicht in kg"; GEWICHT
INPUT "Koerpergroesse in m"; GROESSE

PRINT "Dein BMI ist ";BMI(GEWICHT,GROESSE)

FUNCTION BMI(GEWICHT,GROESSE)

  BMI=GEWICHT/(GROESSE*GROESSE)

END FUNCTION
----

Damit übernimmt das Hauptprogramm die Eingabe und Ausgabe, während die
Funktion ausschließlich für die Berechnung zuständig ist.

[TIP]
====
Genau darin liegt ein wichtiger Vorteil von Funktionen: Eine Berechnung wird
an einer Stelle definiert und kann anschließend überall im Programm verwendet
werden.
====

=== Zusammenfassung

In diesem Kapitel hast du gelernt, Programme in kleinere Bausteine aufzuteilen
und dadurch übersichtlicher zu strukturieren.

Du kannst nun:

* eigene Unterprogramme mit `SUB ... END SUB` erstellen
* eigene Funktionen mit `FUNCTION ... END FUNCTION` schreiben
* Parameter an Unterprogramme und Funktionen übergeben
* Werte aus Funktionen zurückgeben
* wiederkehrende Aufgaben in Unterprogrammen zusammenfassen
* Berechnungen in eigenen Funktionen kapseln
* `SUB` und `FUNCTION` gemeinsam in einem Programm verwenden

Mit diesen Werkzeugen lassen sich auch größere Programme übersichtlich
aufbauen und einzelne Programmteile wiederverwenden.
