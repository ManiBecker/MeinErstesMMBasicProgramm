== Arrays

image::bilder/11_arrays.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* was ein Array ist
* wie Arrays mit `DIM` angelegt werden
* wie Werte in Arrays gespeichert und wieder ausgelesen werden
* wie Arrays mit `FOR`-Schleifen verarbeitet werden
* wie Zahlen- und Textarrays verwendet werden
* wie ein Array Zustände speichern kann
* wie mehrdimensionale Arrays aufgebaut sind
* wie Daten in Zeilen und Spalten organisiert werden

Am Ende des Kapitels kannst du viele zusammengehörige Werte übersichtlich
speichern und verarbeiten.

=== Das Problem

In unserem Zahlenratespiel könnten mehrere Spieler gegeneinander antreten.

Für jeden Spieler möchten wir die Anzahl der benötigten Versuche speichern.

Ohne Arrays könnte das so aussehen:

[source,basic]
----
VERSUCH0=5
VERSUCH1=8
VERSUCH2=3
VERSUCH3=6
VERSUCH4=4
----

Das funktioniert.

Aber was passiert bei 20 Spielern?

Oder 100 Spielern?

Es muss einen besseren Weg geben.

=== Die Lösung: Arrays

Ein indexterm:[Arrays] Array ist eine Sammlung von Variablen mit demselben Namen.

Jedes indexterm:[Array-Elemente] Element besitzt eine Nummer, den sogenannten
indexterm:[Index] Index.

Bevor ein Array verwendet werden kann, muss es mit indexterm:[DIM] `DIM` angelegt werden.

[source,basic]
----
DIM VERSUCH(4)
----

[IMPORTANT]
====
MMBasic nummeriert Array-Elemente standardmäßig ab 0.

Das Array

[source,basic]
----
DIM VERSUCH(4)
----

enthält die Elemente

[source]
----
VERSUCH(0)
VERSUCH(1)
VERSUCH(2)
VERSUCH(3)
VERSUCH(4)
----

also insgesamt fünf Speicherplätze.
====

=== Werte speichern

Werte werden wie bei normalen Variablen gespeichert.

[source,basic]
----
DIM VERSUCH(4)

VERSUCH(0)=5
VERSUCH(1)=8
VERSUCH(2)=3
VERSUCH(3)=6
VERSUCH(4)=4
----

=== Werte ausgeben

Auf einzelne Elemente kann direkt zugegriffen werden.

[source,basic]
----
PRINT VERSUCH(0)
PRINT VERSUCH(1)
PRINT VERSUCH(2)
----

Ausgabe:

[source]
----
5
8
3
----

=== Arrays und FOR-Schleifen

Arrays und FOR-Schleifen sind ein perfektes Team.

[source,basic]
----
DIM VERSUCH(4)

FOR I=0 TO 4

  Print "Gib den";i+1;". von 5 Zahlenwerten ein";

  INPUT VERSUCH(I)

NEXT I
----

Die eingegebenen Werte werden automatisch in den Array-Elementen gespeichert.

=== Alle Werte ausgeben

[source,basic]
----
FOR I=0 TO 4

  PRINT VERSUCH(I)

NEXT I
----

=== Den Durchschnitt berechnen

Arrays eignen sich hervorragend für Berechnungen.

[source,basic]
----
DIM VERSUCH(4)

SUMME=0

FOR I=0 TO 4

  INPUT VERSUCH(I)

  SUMME=SUMME+VERSUCH(I)

NEXT I

PRINT
PRINT "Durchschnitt:"
PRINT SUMME/5
----

=== Den besten Spieler finden

Nun suchen wir die kleinste Anzahl von Versuchen.

[source,basic]
----
DIM VERSUCH(4)

FOR I=0 TO 4

  INPUT VERSUCH(I)

NEXT I

BEST=VERSUCH(0)

FOR I=1 TO 4

  IF VERSUCH(I)<BEST THEN
    BEST=VERSUCH(I)
  ENDIF

NEXT I

PRINT
PRINT "Bester Spieler:"
PRINT BEST;" Versuche"
----

=== Arrays initialisieren

Arrays können bereits beim Anlegen mit Werten gefüllt werden.

[source,basic]
----
DIM NAME$(2)=("Manfred","Geoff","Peter")
----

Anschließend können die Werte direkt verwendet werden.

[source,basic]
----
PRINT NAME$(0)
PRINT NAME$(1)
PRINT NAME$(2)
----

Ausgabe:

[source]
----
Manfred
Geoff
Peter
----

SPIELER$(0)="Manfred"
SPIELER$(1)="Geoff"
SPIELER$(2)="Peter"

Ausgabe:

FOR I=0 TO 4

Ausgabe:

Manfred
Geoff
Peter
Tom
Sarah

=== Würfelergebnisse speichern

In Kapitel 7 haben wir einen Würfel simuliert.

Mit einem Array können wir mehrere Würfe speichern.

[source,basic]
----
DIM WURF(9)

FOR I=0 TO 9

  WURF(I)=INT(RND*6)+1

NEXT I

FOR I=0 TO 9

  PRINT WURF(I)

NEXT I
----

Mögliche Ausgabe:

[source]
----
4
2
6
1
5
3
2
4
6
1
----

=== Eine Wertetabelle speichern

In Kapitel 6 haben wir eine mathematische Funktion berechnet.

Mit Arrays können wir die Ergebnisse speichern.

[source,basic]
----
DIM Y(10)

FOR X=0 TO 10

  Y(X)=0.5*X^2+X+0.5

NEXT X

FOR X=0 TO 10

  PRINT X;"  ";Y(X)

NEXT X
----

=== Lottozahlen ohne Wiederholung

In Kapitel 7 haben wir bereits sechs indexterm:[Lottozahlen] Lottozahlen erzeugt.
Damals konnten die Zahlen allerdings noch mehrfach auftreten.

Inzwischen kennen wir Arrays und können dieses Problem lösen.

Für jede der 49 möglichen Lottozahlen merken wir uns in einem Array, ob sie
bereits gezogen wurde. Dazu verwenden wir die beiden Konstanten
indexterm:[TRUE] `TRUE` und indexterm:[FALSE] `FALSE`.

Mit indexterm:[CONST] `CONST` können wir einen Namen mit einem festen Wert
verbinden. Anders als bei einer Variablen kann dieser Wert während des
Programms nicht mehr verändert werden.

[source,basic]
----
CONST TRUE=1
CONST FALSE=0
----

Damit steht `TRUE` für den Wert 1 und `FALSE` für den Wert 0. Im Programm
können wir dadurch beispielsweise schreiben:

[source,basic]
----
GEZOGEN(22)=TRUE
----

Das ist leichter verständlich als:

[source,basic]
----
GEZOGEN(22)=1
----

[NOTE]
====
`TRUE` und `FALSE` sind hier lediglich Namen für die Zahlenwerte 1 und 0.

Wenn wir schreiben:

[source,basic]
----
GEZOGEN(22)=TRUE
----

wird im Array nicht das Wort `TRUE` gespeichert. Da wir zuvor

[source,basic]
----
CONST TRUE=1
CONST FALSE=0
----

definiert haben, speichert MMBasic tatsächlich den Zahlenwert `1` im
Array-Element `GEZOGEN(22)`.

Entsprechend bedeutet:

[source,basic]
----
GEZOGEN(22)=FALSE
----

dass dort der Zahlenwert `0` gespeichert wird.

Die Konstanten `TRUE` und `FALSE` machen das Programm lediglich leichter
lesbar.
====

Mit diesem Wissen können wir nun unsere Lottoziehung programmieren. Das Array
`GEZOGEN()` merkt sich dabei für jede Zahl von 1 bis 49, ob sie bereits gezogen
wurde:

[source,basic]
----
CONST TRUE=1
CONST FALSE=0

DIM GEZOGEN(49)

DO

  ' Array fuer eine neue Ziehung loeschen
  FOR ZAHL=1 TO 49
    GEZOGEN(ZAHL)=FALSE
  NEXT ZAHL

  ' Sechs verschiedene Lottozahlen ziehen
  FOR I=1 TO 6

    DO
      ZAHL=INT(RND*49)+1
    LOOP WHILE GEZOGEN(ZAHL)=TRUE

    GEZOGEN(ZAHL)=TRUE

  NEXT I

  ' Zusatzzahl ziehen
  DO
    ZUSATZZAHL=INT(RND*49)+1
  LOOP WHILE GEZOGEN(ZUSATZZAHL)=TRUE

  ' Lottozahlen sortiert ausgeben
  PRINT "Ziehung der Lottozahlen: ";

  ERSTE=TRUE

  FOR ZAHL=1 TO 49

    IF GEZOGEN(ZAHL)=TRUE THEN

      IF ERSTE=FALSE THEN PRINT ", ";

      PRINT ZAHL;
      ERSTE=FALSE

    ENDIF

  NEXT ZAHL

  PRINT ". Zusatzzahl: ";ZUSATZZAHL

  ' Weitere Ziehung?
  INPUT "Noch einmal ziehen (J/N)"; NOCHMAL$

LOOP WHILE UCASE$(NOCHMAL$)="J"
----

Eine mögliche Ausgabe ist:

[source]
----
Ziehung der Lottozahlen: 4, 6, 22, 33, 34, 40. Zusatzzahl: 3
Noch einmal ziehen (J/N)? J

Ziehung der Lottozahlen: 2, 9, 14, 21, 37, 48. Zusatzzahl: 16
Noch einmal ziehen (J/N)? N
----

==== Das Array als Merkspeicher

Das Array `GEZOGEN()` dient als Gedächtnis für unsere Lottoziehung.

Zu Beginn einer neuen Ziehung setzen wir alle Elemente auf `FALSE`:

[source,basic]
----
FOR ZAHL=1 TO 49
  GEZOGEN(ZAHL)=FALSE
NEXT ZAHL
----

Damit ist zunächst keine der 49 möglichen Zahlen als gezogen markiert.

Wird beispielsweise die Zahl 22 gezogen, setzen wir das entsprechende
Array-Element auf `TRUE`:

[source,basic]
----
GEZOGEN(22)=TRUE
----

Bei jeder weiteren Ziehung prüfen wir, ob die erzeugte Zahl bereits als
gezogen markiert ist:

[source,basic]
----
DO
  ZAHL=INT(RND*49)+1
LOOP WHILE GEZOGEN(ZAHL)=TRUE
----

Solange die gezogene Zahl bereits im Array mit `TRUE` markiert ist, wird eine
neue Zufallszahl erzeugt. Erst bei einer noch nicht gezogenen Zahl wird die
Schleife beendet.

Auf diese Weise erhalten wir sechs verschiedene Lottozahlen.

==== Die Zusatzzahl

Auch die Zusatzzahl darf keine der sechs zuvor gezogenen Lottozahlen sein.
Deshalb verwenden wir bei ihrer Ermittlung dieselbe Prüfung:

[source,basic]
----
DO
  ZUSATZZAHL=INT(RND*49)+1
LOOP WHILE GEZOGEN(ZUSATZZAHL)=TRUE
----

Da die Zusatzzahl anschließend nicht mehr für weitere Ziehungen geprüft werden
muss, brauchen wir sie nicht zusätzlich im Array zu markieren.

==== Sortieren ganz ohne Sortieralgorithmus

Für die Ausgabe benötigen wir keinen eigenen Sortieralgorithmus.

Das Array `GEZOGEN()` besitzt für jede mögliche Lottozahl von 1 bis 49 ein
Element. Deshalb können wir das Array einfach in dieser Reihenfolge
durchlaufen:

[source,basic]
----
FOR ZAHL=1 TO 49
  IF GEZOGEN(ZAHL)=TRUE THEN
    PRINT ZAHL
  ENDIF
NEXT ZAHL
----

Da wir bei 1 beginnen und bei 49 aufhören, werden die gezogenen Zahlen
automatisch in aufsteigender Reihenfolge ausgegeben.

Für die gewünschte Ausgabe in einer einzigen Zeile benötigen wir noch die
Variable `ERSTE`. Sie merkt sich, ob bereits eine Lottozahl ausgegeben wurde:

[source,basic]
----
ERSTE=TRUE

FOR ZAHL=1 TO 49

  IF GEZOGEN(ZAHL)=TRUE THEN

    IF ERSTE=FALSE THEN PRINT ", ";

    PRINT ZAHL;
    ERSTE=FALSE

  ENDIF

NEXT ZAHL
----

Vor der ersten Lottozahl wird dadurch kein Komma ausgegeben. Vor allen
folgenden Zahlen dagegen schon.

==== Eine weitere Ziehung

Nach jeder Ziehung fragen wir den Benutzer, ob eine weitere Ziehung
durchgeführt werden soll:

[source,basic]
----
INPUT "Noch einmal ziehen (J/N)"; NOCHMAL$
----

Die gesamte Lottoziehung befindet sich deshalb in einer weiteren
`DO ... LOOP`-Schleife:

[source,basic]
----
DO

  ' Lottoziehung

  INPUT "Noch einmal ziehen (J/N)"; NOCHMAL$

LOOP WHILE UCASE$(NOCHMAL$)="J"
----

Mit `UCASE$()` wird die Eingabe vor dem Vergleich in Großbuchstaben
umgewandelt. Deshalb werden sowohl `J` als auch `j` akzeptiert.

Wird etwas anderes eingegeben, endet die Schleife und damit das Programm.

[TIP]
====
Dieses Beispiel zeigt einen weiteren Vorteil von Arrays: Sie können nicht nur
Werte speichern, sondern auch Zustände festhalten.

`GEZOGEN(22)=TRUE` lässt sich fast wie ein Satz lesen:

„Die Zahl 22 wurde bereits gezogen.“

Die Konstanten `TRUE` und `FALSE` machen solche Abfragen leichter lesbar als
die direkte Verwendung der Zahlen 1 und 0.
====

=== Mehrdimensionale Arrays

Ein indexterm:[Arrays,Mehrdimensionale Arrays]indexterm:[Mehrdimensionale Arrays] Array kann mehrere Dimensionen besitzen.

Stell dir eine Tabelle mit Zeilen und Spalten vor.

In einer kleinen Notenverwaltung stehen die Zeilen für die Schüler und die Spalten für die einzelnen Fächer.

[source,basic]
----
DIM SCHUELER$(4)
SCHUELER$(0)="Anna"
SCHUELER$(1)="Ben"
SCHUELER$(2)="Clara"
SCHUELER$(3)="David"
SCHUELER$(4)="Emma"

DIM FACH$(2)
FACH$(0)="Deutsch"
FACH$(1)="Englisch"
FACH$(2)="Mathe"

DIM NOTE(4,2)

' Zufällige Noten vergeben
FOR S=0 TO 4
  FOR F=0 TO 2
    NOTE(S,F)=INT(RND*6)+1
  NEXT F
NEXT S

' Tabelle ausgeben
PRINT "Schüler",
FOR F=0 TO 2
  PRINT FACH$(F),
NEXT F
PRINT

FOR S=0 TO 4
  PRINT SCHUELER$(S),
  FOR F=0 TO 2
    PRINT NOTE(S,F),
  NEXT F
  PRINT
NEXT S
----

Die erste Dimension (`S`) beschreibt den Schüler.

Die zweite Dimension (`F`) beschreibt das Fach.

Der Zugriff

[source,basic]
----
NOTE(2,1)=1
----

bedeutet:

* Schüler Nummer 2
* Fach Nummer 1 (Englisch)
* Note 1

=== Beispiel: Ein Spielfeld im Array

Ein zweidimensionales Array eignet sich nicht nur für Tabellen. Auch ein
Spielfeld kann als Array gespeichert werden.

Dabei beschreibt die erste Dimension die Zeile und die zweite Dimension die
Spalte.

Wir legen ein Spielfeld mit 5 Zeilen und 10 Spalten an:

[source,basic]
----
DIM FELD$(4,9)
----

Zunächst füllen wir alle Felder mit einem Punkt:

[source,basic]
----
FOR ZEILE=0 TO 4
  FOR SPALTE=0 TO 9
    FELD$(ZEILE,SPALTE)="."
  NEXT SPALTE
NEXT ZEILE
----

Nun setzen wir an einigen Positionen Hindernisse und eine Spielfigur:

[source,basic]
----
FELD$(1,3)="#"
FELD$(2,6)="#"
FELD$(3,4)="#"
FELD$(2,2)="X"
----

Anschließend geben wir das gesamte Spielfeld aus:

[source,basic]
----
FOR ZEILE=0 TO 4
  FOR SPALTE=0 TO 9
    PRINT FELD$(ZEILE,SPALTE);
  NEXT SPALTE
  PRINT
NEXT ZEILE
----

Ausgabe:

[source]
----
..........
...#......
..X...#...
....#.....
..........
----

Jedes Element des Arrays entspricht genau einer Position auf dem Spielfeld.

Der Zugriff

[source,basic]
----
FELD$(2,2)
----

bezeichnet beispielsweise das Feld in Zeile 2 und Spalte 2. Dort befindet
sich in unserem Beispiel die Spielfigur `X`.

[TIP]
====
Zweidimensionale Arrays werden häufig verwendet, wenn Daten in Zeilen und
Spalten angeordnet sind. Neben Tabellen können damit beispielsweise
Spielfelder, Labyrinthe oder Karten gespeichert werden.
====
