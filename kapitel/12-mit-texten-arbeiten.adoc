== Mit Texten arbeiten

image::bilder/12_texte.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* Texte in Variablen zu speichern
* Texte einzugeben und auszugeben
* die Länge eines Textes zu bestimmen
* Teile eines Textes auszulesen
* Texte in Groß- und Kleinbuchstaben umzuwandeln
* in Texten zu suchen
* Zahlen und Texte ineinander umzuwandeln
* Datum und Uhrzeit zu verwenden
* mehrere Stringfunktionen in einem Programm miteinander zu kombinieren

Am Ende des Kapitels kannst du Texte in deinen Programmen verarbeiten und
auswerten und die verschiedenen Möglichkeiten der Stringverarbeitung in
einem kleinen Spiel praktisch einsetzen.

=== Zahlen und Texte

Bisher haben wir hauptsächlich mit Zahlen gearbeitet.

Zum Beispiel:

[source,basic]
----
ALTER=60
PUNKTE=125
----

Programme arbeiten aber nicht nur mit Zahlen.

Oft müssen auch Texte verarbeitet werden.

Zum Beispiel:

* Namen
* Adressen
* Dateinamen
* Antworten auf Fragen
* Meldungen

Texte werden in MMBasic in String-Variablen gespeichert.

String-Variablen erkennt man am Dollarzeichen am Ende des Namens.

[source,basic]
----
NAME$="Manfred"
ORT$="Schwetzingen"
----

=== Wie lang darf ein Text sein?

Normale indexterm:[Zeichenketten] Zeichenketten können in MMBasic maximal 255 Zeichen enthalten.

Für die meisten Programme ist das vollkommen ausreichend.

Beispiele:

* Namen
* Dateinamen
* Benutzereingaben
* Meldungen
* kurze Texte

[source,basic]
----
NAME$="Manfred"
----

Für längere Texte und größere Datenmengen stellt MMBasic sogenannte
indexterm:[Long Strings] Long Strings zur Verfügung.

Wie Long Strings verwendet werden, sehen wir später im Kapitel zur
seriellen Kommunikation.

=== Texte ausgeben

Texte können wie Zahlen ausgegeben werden.

[source,basic]
----
NAME$="Manfred"

PRINT NAME$
----

Ausgabe:

[source]
----
Manfred
----

=== Texte eingeben

Mit INPUT können auch Texte eingegeben werden.

[source,basic]
----
INPUT NAME$

PRINT "Hallo ";NAME$
----

Beispiel:

[source]
----
? Manfred

Hallo Manfred
----

=== Texte verbinden

Mehrere Texte können in einer Ausgabe kombiniert werden.

[source,basic]
----
VORNAME$="Manfred"
NACHNAME$="Becker"

PRINT VORNAME$;" ";NACHNAME$
----

Ausgabe:

[source]
----
Manfred Becker
----

=== Die Länge eines Textes bestimmen

Mit indexterm:[String-Funktionen,LEN]indexterm:[LEN] `LEN()` kann die Anzahl der Zeichen ermittelt werden.

[source,basic]
----
NAME$="Manfred"

PRINT LEN(NAME$)
----

Ausgabe:

[source]
----
7
----

Jeder Buchstabe zählt als ein Zeichen.

Auch Leerzeichen werden mitgezählt.

=== Das erste Zeichen ermitteln

Mit indexterm:[String-Funktionen,LEFT$]indexterm:[LEFT$] `LEFT$()` können Zeichen vom Anfang eines Textes gelesen werden.

[source,basic]
----
NAME$="Manfred"

PRINT LEFT$(NAME$,1)
----

Ausgabe:

[source]
----
M
----

=== Mehrere Zeichen vom Anfang lesen

[source,basic]
----
NAME$="Manfred"

PRINT LEFT$(NAME$,3)
----

Ausgabe:

[source]
----
Man
----

=== Zeichen vom Ende lesen

Mit indexterm:[String-Funktionen,RIGHT$]indexterm:[RIGHT$] `RIGHT$()` können Zeichen vom Ende eines Textes gelesen werden.

[source,basic]
----
NAME$="Manfred"

PRINT RIGHT$(NAME$,3)
----

Ausgabe:

[source]
----
red
----

=== Zeichen aus der Mitte lesen

Mit indexterm:[String-Funktionen,MID$]indexterm:[MID$] `MID$()` können Zeichen aus der Mitte eines Textes gelesen werden.

[source,basic]
----
NAME$="Manfred"

PRINT MID$(NAME$,3,2)
----

Ausgabe:

[source]
----
nf
----

Die Zahl 3 gibt die Startposition an.

Die Zahl 2 gibt die Anzahl der Zeichen an.

=== Groß- und Kleinbuchstaben

Mit indexterm:[String-Funktionen,UCASE$]indexterm:[UCASE$] `UCASE$()` wird ein Text in Großbuchstaben umgewandelt.

[source,basic]
----
NAME$="Manfred"

PRINT UCASE$(NAME$)
----

Ausgabe:

[source]
----
MANFRED
----

Mit indexterm:[String-Funktionen,LCASE$]indexterm:[LCASE$] `LCASE$()` wird ein Text in Kleinbuchstaben umgewandelt.

[source,basic]
----
NAME$="Manfred"

PRINT LCASE$(NAME$)
----

Ausgabe:

[source]
----
manfred
----

=== Texte vergleichen

Texte können mit IF verglichen werden.

[source,basic]
----
INPUT ANTWORT$

IF ANTWORT$="JA" THEN
  PRINT "Richtig"
ENDIF
----

Dabei muss die Schreibweise exakt übereinstimmen.

Die Eingabe

[source]
----
ja
----

ist nicht dasselbe wie

[source]
----
JA
----

=== Groß- und Kleinschreibung ignorieren

Oft soll die Schreibweise keine Rolle spielen.

Mit UCASE$() lässt sich das einfach lösen.

[source,basic]
----
INPUT ANTWORT$

IF UCASE$(ANTWORT$)="JA" THEN
  PRINT "Richtig"
ENDIF
----

Jetzt werden beispielsweise

[source]
----
JA
Ja
ja
jA
----

alle akzeptiert.

=== In einem Text suchen

Mit indexterm:[String-Funktionen,INSTR]indexterm:[INSTR] `INSTR()` kann nach einem Zeichen oder einer Zeichenfolge gesucht werden.

[source,basic]
----
TEXT$="MMBasic macht Spass"

PRINT INSTR(TEXT$,"macht")
----

Ausgabe:

[source]
----
9
----

Die Funktion liefert die Position zurück, an der der gesuchte Text beginnt.

Wird der Text nicht gefunden, liefert INSTR() den Wert 0.

[source,basic]
----
TEXT$="MMBasic macht Spass"

IF INSTR(TEXT$,"Basic")>0 THEN
  PRINT "Text gefunden"
ELSE
  PRINT "Text nicht gefunden"
ENDIF
----

=== Zahlen und Texte umwandeln

Mit indexterm:[Konvertierungsfunktionen,VAL]indexterm:[VAL] `VAL()` wird ein Text in eine Zahl umgewandelt.

[source,basic]
----
ZAHL=VAL("123")

PRINT ZAHL+1
----

Ausgabe:

[source]
----
124
----

Mit indexterm:[Konvertierungsfunktionen,STR$]indexterm:[STR$] `STR$()` wird umgekehrt eine Zahl in einen Text umgewandelt.

[source,basic]
----
TEXT$=STR$(123)

PRINT "Die Zahl lautet ";TEXT$
----

=== Datum und Uhrzeit

MMBasic stellt das aktuelle Datum und die aktuelle Uhrzeit als Zeichenketten zur Verfügung. Dafür stehen indexterm:[Datum und Uhrzeit,DATE$]indexterm:[DATE$] `DATE$` und indexterm:[Datum und Uhrzeit,TIME$]indexterm:[DATE$] `TIME$` bereit.

[source,basic]
----
PRINT DATE$
PRINT TIME$
----

Die genaue Darstellung hängt von der Konfiguration des Systems ab.

Da Datum und Uhrzeit Zeichenketten sind, können sie mit den bekannten String-Funktionen verarbeitet werden.

[source,basic]
----
PRINT "Heute ist ";DATE$
PRINT "Es ist ";TIME$
----

=== Begrüßung abhängig von der Uhrzeit

Mit LEFT$() lässt sich die Stunde aus der Uhrzeit auslesen.

Da LEFT$() einen Text zurückliefert, wird dieser mit VAL() in eine Zahl umgewandelt.

[source,basic]
----
STUNDE=VAL(LEFT$(TIME$,2))

IF STUNDE<12 THEN
  PRINT "Guten Morgen!"
ELSEIF STUNDE<18 THEN
  PRINT "Guten Tag!"
ELSE
  PRINT "Guten Abend!"
ENDIF
----

=== Ein kleines Praxisprogramm

Das folgende Programm verwendet viele der neuen Funktionen.

[source,basic]
----
INPUT NAME$

PRINT
PRINT "Hallo ";NAME$
PRINT

PRINT "Heute ist ";DATE$
PRINT "Aktuelle Uhrzeit: ";TIME$
PRINT

PRINT "Dein Name hat ";LEN(NAME$);" Zeichen."

PRINT "Er beginnt mit ";LEFT$(NAME$,1)

PRINT "Er endet mit ";RIGHT$(NAME$,1)

IF VAL(LEFT$(TIME$,2))<12 THEN
  PRINT "Guten Morgen!"
ELSEIF VAL(LEFT$(TIME$,2))<18 THEN
  PRINT "Guten Tag!"
ELSE
  PRINT "Guten Abend!"
ENDIF
----

=== Praxisbeispiel: Hangman

Wir haben inzwischen verschiedene Möglichkeiten kennengelernt, Zeichenketten
zu untersuchen und zu verändern.

Zeit, diese Funktionen in einem kleinen Spiel miteinander zu kombinieren.

Beim klassischen Hangman-Spiel muss ein unbekanntes Wort Buchstabe für
Buchstabe erraten werden. Zu Beginn sehen wir nur, wie viele Buchstaben das
gesuchte Wort besitzt:

[source]
----
_ _ _ _ _ _ _
----

Nach jeder Eingabe werden alle richtig geratenen Buchstaben aufgedeckt.

Für unser erstes Spiel verwenden wir das Wort `MMBASIC`.

==== Das gesuchte Wort

Das gesuchte Wort speichern wir in einer Zeichenkette:

[source,basic]
----
WORT$="MMBASIC"
----

Mit `LEN()` können wir feststellen, aus wie vielen Zeichen das Wort besteht:

[source,basic]
----
PRINT LEN(WORT$)
----

Die Ausgabe lautet:

[source]
----
7
----

Diese Information benötigen wir später, um alle Buchstaben des Wortes
nacheinander zu untersuchen.

==== Bereits geratene Buchstaben speichern

Wir benötigen außerdem eine Zeichenkette, in der wir uns die bereits
eingegebenen Buchstaben merken:

[source,basic]
----
GERATEN$=""
----

Gibt der Spieler beispielsweise den Buchstaben `A` ein, hängen wir ihn an
diese Zeichenkette an:

[source,basic]
----
GERATEN$=GERATEN$+"A"
----

Nach mehreren Versuchen könnte `GERATEN$` beispielsweise so aussehen:

[source]
----
AMBS
----

Damit weiß unser Programm, welche Buchstaben bereits geraten wurden.

==== Einen einzelnen Buchstaben untersuchen

Mit `MID$()` können wir einen einzelnen Buchstaben aus dem gesuchten Wort
herausholen:

[source,basic]
----
PRINT MID$(WORT$,3,1)
----

Beim Wort `MMBASIC` erhalten wir:

[source]
----
B
----

Die Zahl `3` gibt die Position an und die Zahl `1`, dass genau ein Zeichen
gelesen werden soll.

Mit einer `FOR`-Schleife können wir deshalb das gesamte Wort Zeichen für
Zeichen durchlaufen:

[source,basic]
----
FOR I=1 TO LEN(WORT$)
  PRINT MID$(WORT$,I,1)
NEXT I
----

==== Welche Buchstaben dürfen wir anzeigen?

Jetzt verbinden wir `MID$()` mit `INSTR()`.

Für jeden Buchstaben des gesuchten Wortes prüfen wir, ob er bereits in
`GERATEN$` vorkommt:

[source,basic]
----
FOR I=1 TO LEN(WORT$)

  BUCHSTABE$=MID$(WORT$,I,1)

  IF INSTR(GERATEN$,BUCHSTABE$)>0 THEN
    PRINT BUCHSTABE$;" ";
  ELSE
    PRINT "_ ";
  ENDIF

NEXT I

PRINT
----

Enthält `GERATEN$` beispielsweise

[source,basic]
----
GERATEN$="AMB"
----

erscheint:

[source]
----
M M B A _ _ _
----

Damit haben wir bereits den wichtigsten Teil unseres Hangman-Spiels.

==== Groß- und Kleinschreibung

Der Spieler soll sowohl `m` als auch `M` eingeben dürfen.

Mit `UCASE$()` wandeln wir die Eingabe deshalb in Großbuchstaben um:

[source,basic]
----
INPUT "Buchstabe"; EINGABE$

EINGABE$=UCASE$(EINGABE$)
----

Für das Spiel macht es dadurch keinen Unterschied, ob der Spieler `a` oder
`A` eingibt.

==== Doppelte Eingaben erkennen

Bevor wir einen Buchstaben zu `GERATEN$` hinzufügen, können wir mit `INSTR()`
prüfen, ob er dort bereits vorhanden ist:

[source,basic]
----
IF INSTR(GERATEN$,EINGABE$)>0 THEN
  PRINT "Diesen Buchstaben hast du bereits versucht."
ELSE
  GERATEN$=GERATEN$+EINGABE$
ENDIF
----

Auch hier zeigt sich, wie praktisch Zeichenketten sein können: `GERATEN$`
dient gleichzeitig als Speicher für alle bisher eingegebenen Buchstaben.

==== Das vollständige Spiel

Nun setzen wir die einzelnen Teile zusammen.

Wie bei unserer Lottoziehung verwenden wir wieder die Konstanten `TRUE` und
`FALSE`. Die Variable `FERTIG` merkt sich damit, ob alle Buchstaben des
gesuchten Wortes bereits gefunden wurden.

Der Spieler hat acht Fehlversuche. Nach jedem Versuch wird das Wort erneut
angezeigt.

[source,basic]
----
CONST TRUE=1
CONST FALSE=0

WORT$="MMBASIC"
GERATEN$=""
FEHLER=0
MAXFEHLER=8

DO

  PRINT

  ' Wort anzeigen
  FERTIG=TRUE

  FOR I=1 TO LEN(WORT$)

    BUCHSTABE$=MID$(WORT$,I,1)

    IF INSTR(GERATEN$,BUCHSTABE$)>0 THEN
      PRINT BUCHSTABE$;" ";
    ELSE
      PRINT "_ ";
      FERTIG=FALSE
    ENDIF

  NEXT I

  PRINT
  PRINT

  ' Wurde das ganze Wort erraten?
  IF FERTIG=TRUE THEN

    PRINT "Geschafft!"
    PRINT "Du hast das Wort ";WORT$;" erraten."

  ELSE

    PRINT "Fehlversuche: ";FEHLER;" von ";MAXFEHLER
    INPUT "Buchstabe"; EINGABE$

    EINGABE$=UCASE$(EINGABE$)

    ' Nur das erste eingegebene Zeichen verwenden
    EINGABE$=LEFT$(EINGABE$,1)

    IF INSTR(GERATEN$,EINGABE$)>0 THEN

      PRINT "Diesen Buchstaben hast du bereits versucht."

    ELSE

      GERATEN$=GERATEN$+EINGABE$

      IF INSTR(WORT$,EINGABE$)=0 THEN
        FEHLER=FEHLER+1
        PRINT "Leider falsch!"
      ENDIF

    ENDIF

  ENDIF

LOOP UNTIL FERTIG=TRUE OR FEHLER=MAXFEHLER

PRINT

IF FERTIG=FALSE THEN
  PRINT "Leider verloren!"
  PRINT "Das gesuchte Wort war ";WORT$;"."
ENDIF
----

Eine mögliche Runde könnte so aussehen:

[source]
----
_ _ _ _ _ _ _

Fehlversuche: 0 von 8
Buchstabe? A

_ _ _ A _ _ _

Fehlversuche: 0 von 8
Buchstabe? X
Leider falsch!

_ _ _ A _ _ _

Fehlversuche: 1 von 8
Buchstabe? M

M M _ A _ _ _

Fehlversuche: 1 von 8
Buchstabe? B

M M B A _ _ _

...

M M B A S I C

Geschafft!
Du hast das Wort MMBASIC erraten.
----

==== Viele Stringfunktionen in einem Spiel

Unser kleines Hangman-Spiel verwendet gleich mehrere der Stringfunktionen,
die wir in diesem Kapitel kennengelernt haben:

[cols="1,3",options="header"]
|===
|Funktion |Aufgabe im Spiel

|`LEN()`
|ermittelt die Länge des gesuchten Wortes

|`MID$()`
|liest einzelne Buchstaben aus dem Wort

|`INSTR()`
|sucht nach bereits geratenen oder richtigen Buchstaben

|`UCASE$()`
|wandelt die Eingabe in Großbuchstaben um

|`LEFT$()`
|verwendet nur das erste eingegebene Zeichen

|`+`
|fügt einen neuen Buchstaben an `GERATEN$` an
|===

Aus einzelnen Befehlen zur Textverarbeitung ist damit ein vollständiges
kleines Spiel entstanden.

=== Experimentiere!

Probiere folgende Änderungen aus:

* Gib die ersten drei Zeichen eines Namens aus.
* Gib die letzten drei Zeichen aus.
* Wandle einen Namen in Großbuchstaben um.
* Wandle einen Namen in Kleinbuchstaben um.
* Suche nach einem Wort in einem Text.
* Ändere das gesuchte Wort im Hangman-Spiel.

  neue Runde zufällig eines davon aus.

=== Zusammenfassung

In diesem Kapitel hast du gelernt, mit Texten und Zeichenketten zu arbeiten.

Du kennst nun:

* String-Variablen
* `LEN()`
* `LEFT$()`
* `MID$()`
* `RIGHT$()`
* `UCASE$()`
* `LCASE$()`
* `INSTR()`
* `VAL()`
* `STR$()`
* `DATE$`
* `TIME$`

Du kannst damit Texte speichern, verändern, durchsuchen und auswerten.

Im Hangman-Spiel hast du außerdem gesehen, wie mehrere dieser Funktionen
zusammen eingesetzt werden können. Dabei haben wir einen String sogar als
Speicher für die bereits geratenen Buchstaben verwendet.

Im nächsten Kapitel werden wir das bisher Gelernte in einem größeren
Praxisprojekt einsetzen.
