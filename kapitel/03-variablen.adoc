== Variablen

image::bilder/03_variablen.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* was Variablen sind
* wie Werte gespeichert werden
* wie Variablen benannt werden
* welche grundlegenden Datentypen es gibt
* wie Variablen mit `DIM` deklariert werden

Am Ende des Kapitels kannst du eigene Werte speichern und weiterverarbeiten.

=== Was ist eine Variable?

Eine indexterm:[Variablen] Variable ist ein Speicherplatz für einen Wert.

Du kannst dir eine Variable wie eine beschriftete Schachtel vorstellen.

In diese Schachtel kannst du einen Wert hineinlegen und später wieder darauf zugreifen.

=== Unsere erste Variable

Gib folgende Zeilen ein:

indexterm:[PRINT]

[source,basic]
----
A=10
PRINT A
----

Ausgabe:

[source]
----
10
----

MMBasic speichert den Wert 10 in der Variablen `A`.

Mit `PRINT` kann der gespeicherte Wert angezeigt werden.

=== Mehrere Variablen verwenden

Natürlich können mehrere Variablen gleichzeitig verwendet werden.

[source,basic]
----
A=10
B=20

PRINT A
PRINT B
----

Ausgabe:

[source]
----
10
20
----

=== Aussagekräftige Variablennamen

Für die ersten Beispiele sind kurze Variablennamen wie `A` und `B` praktisch.
In größeren Programmen ist es jedoch leichter zu verstehen, was eine Variable
enthält, wenn ihr Name den Inhalt beschreibt.

Statt

[source,basic]
----
A=60
B=100
----

kannst du zum Beispiel schreiben:

[source,basic]
----
ALTER=60
PUNKTE=100
----

MMBasic erlaubt dazu längere indexterm:[Variablennamen] Variablennamen.

Ein Variablenname beginnt mit einem Buchstaben. Danach können weitere
Buchstaben, Ziffern, der Unterstrich `_` und der Punkt `.` verwendet werden.

Unterstrich und Punkt können helfen, längere Variablennamen übersichtlicher
zu gestalten. Zum Beispiel:

[source,basic]
----
MAX_PUNKTE=100
SPIELER.NAME$="Manfred"
SPIELER.PUNKTE=50
----

`MAX_PUNKTE` besteht aus zwei Wörtern, die durch einen Unterstrich getrennt
werden. Der Punkt kann verwendet werden, um zusammengehörige Namen zu
strukturieren. `SPIELER.NAME$` und `SPIELER.PUNKTE` lassen beispielsweise
sofort erkennen, dass beide Werte zu einem Spieler gehören.

[TIP]
====
Verwende `_` und `.` nur dann, wenn sie einen Variablennamen wirklich
verständlicher machen. Entscheidend ist nicht, möglichst lange Namen zu
verwenden, sondern Namen, deren Bedeutung beim Lesen des Programms sofort
erkennbar ist.
====

==== Schlüsselwörter dürfen keine Variablennamen sein

Bei der Wahl eines Variablennamens gibt es noch eine wichtige Regel:
indexterm:[Schlüsselwörter] Schlüsselwörter von MMBasic dürfen nicht als
Variablennamen verwendet werden.

Schlüsselwörter sind Wörter, die in MMBasic bereits eine feste Bedeutung
haben. Dazu gehören beispielsweise Befehle und Anweisungen wie `PRINT`,
`INPUT`, `IF` oder `FOR`.

Folgende Variablennamen wären deshalb nicht zulässig:

[source,basic]
----
PRINT=10
INPUT=20
FOR=5
----

Verwende stattdessen einen Namen, der den Inhalt der Variablen beschreibt:

[source,basic]
----
ANZAHL=10
EINGABE=20
ZAHL=5
----

[NOTE]
====
Da MMBasic bei Variablennamen nicht zwischen Groß- und Kleinschreibung
unterscheidet, lässt sich diese Regel nicht durch eine andere Schreibweise
umgehen. `PRINT`, `Print` und `print` werden gleichermaßen als Schlüsselwort
erkannt.
====

=== Zahlen oder Text? – Ein erster Blick auf Datentypen

Bis jetzt haben unsere Variablen Zahlen enthalten:

[source,basic]
----
A
B
ALTER
PUNKTE
----

MMBasic kann aber auch Texte in Variablen speichern. Dazu verwenden wir eine
indexterm:[String-Variablen] String-Variable. Eine String-Variable erkennst du
am Dollarzeichen `$` am Ende ihres Namens:

[source,basic]
----
NAME$="Manfred"
WOHNORT$="Heidelberg"

PRINT NAME$
PRINT WOHNORT$
----

Das Dollarzeichen `$` zeigt an, dass die Variable einen Text enthält. Solche
Texte werden in der Programmierung als indexterm:[String] *Strings* bezeichnet.

Eine Variable besitzt also einen bestimmten indexterm:[Datentyp] *Datentyp*.
Der Datentyp legt fest, welche Art von Wert in einer Variablen gespeichert
werden kann.

Für den Anfang genügt uns die Unterscheidung zwischen Zahlen und Texten:

[cols="2,2,4",options="header"]
|===
|Beispiel |Datentyp |Typische Verwendung

|`ALTER`
|Zahl
|Alter, Punkte, Messwerte oder Berechnungen

|`NAME$`
|String
|Namen, Texte oder andere Zeichenfolgen
|===

==== Es gibt noch weitere Datentypen

MMBasic kann Zahlen noch genauer unterscheiden. Dafür gibt es besondere
Typkennzeichen, die an einen Variablennamen angehängt werden können:

[cols="1,2,3,3",options="header"]
|===
|Zeichen |Datentyp |Beispiel |Bedeutung

|`$`
|String
|`NAME$`
|Text bzw. Zeichenfolge

|`%`
|Integer
|`PUNKTE%`
|Ganze Zahl

|`!`
|Float
|`TEMPERATUR!`
|Zahl mit Nachkommastellen
|===

Du musst dir diese Datentypen jetzt noch nicht im Detail merken. Wichtig ist
zunächst, dass Variablen unterschiedliche Arten von Werten speichern können.

==== Groß- und Kleinschreibung bei Variablennamen

Bei Variablennamen unterscheidet MMBasic nicht zwischen Groß- und
Kleinschreibung. Die folgenden Schreibweisen bezeichnen deshalb dieselbe
Variable:

[source,basic]
----
ALTER=25
PRINT alter
PRINT Alter
----

Ausgabe:

[source]
----
25
25
----

Das Gleiche gilt auch für String-Variablen:

[source,basic]
----
NAME$="Manfred"
PRINT name$
----

MMBasic erkennt `NAME$` und `name$` als dieselbe Variable.

[TIP]
====
Verwende trotzdem eine einheitliche Schreibweise. In diesem Buch schreiben wir
Variablennamen in den Beispielen überwiegend in Großbuchstaben. So lassen sie
sich im Programmtext leicht erkennen.
====

==== Ein Name – ein Datentyp

Bei den verschiedenen Datentypen gibt es noch eine wichtige Regel:
Ein Variablenname kann in MMBasic nicht gleichzeitig für unterschiedliche
Datentypen verwendet werden.

Es ist also nicht zulässig, beispielsweise diese beiden Variablen im selben
Programm zu verwenden:

[source,basic]
----
WERT%=10
WERT$="zehn"
----

Obwohl `%` eine Integer-Variable und `$` eine String-Variable kennzeichnet,
verwenden beide denselben Basisnamen `WERT`.

[IMPORTANT]
====
Für einen Variablennamen musst du dich für einen Datentyp entscheiden.

Wenn du sowohl einen Zahlenwert als auch einen dazugehörigen Text speichern
möchtest, verwende unterschiedliche Namen:

[source,basic]
----
WERT%=10
WERTTEXT$="zehn"
----
====

=== Variablen ausdrücklich deklarieren

Bisher haben wir Variablen einfach verwendet:

[source,basic]
----
ALTER=60
NAME$="Manfred"
----

MMBasic legt diese Variablen automatisch an, sobald sie zum ersten Mal
verwendet werden. Das ist für unsere ersten Programme sehr praktisch.

Variablen können aber auch ausdrücklich mit indexterm:[DIM] `DIM`
deklariert werden:

[source,basic]
----
DIM ALTER
DIM NAME$

ALTER=60
NAME$="Manfred"
----

Bei größeren Programmen hat diese Schreibweise einen wichtigen Vorteil:
Es wird klar festgelegt, welche Variablen im Programm verwendet werden.

==== Tippfehler mit OPTION EXPLICIT erkennen

Ein Tippfehler in einem Variablennamen kann schwer zu entdecken sein:

[source,basic]
----
PUNKTE=100
PRINT PUNKET
----

MMBasic kann `PUNKET` als neue Variable betrachten, obwohl eigentlich
`PUNKTE` gemeint war.

Mit indexterm:[OPTION EXPLICIT] `OPTION EXPLICIT` kann festgelegt werden,
dass Variablen vor ihrer Verwendung deklariert werden müssen:

[source,basic]
----
OPTION EXPLICIT

DIM PUNKTE
PUNKTE=100

PRINT PUNKTE
----

Ein versehentlich verwendeter Variablenname, der nicht vorher deklariert
wurde, führt dann zu einer Fehlermeldung.

[TIP]
====
Für unsere ersten kleinen Programme verzichten wir zunächst auf
`OPTION EXPLICIT`. Bei größeren Programmen ist es jedoch eine gute
Möglichkeit, Tippfehler in Variablennamen frühzeitig zu entdecken.
====

=== Mit Variablen rechnen

Variablen können in Berechnungen verwendet werden.

[source,basic]
----
A=10
B=20

PRINT A+B
----

Ausgabe:

[source]
----
30
----

Weitere Beispiele:

[source,basic]
----
PRINT A-B
PRINT A*B
PRINT B/A
----

=== Variablen verändern

Der Inhalt einer Variablen kann jederzeit geändert werden.

[source,basic]
----
A=10
PRINT A

A=25
PRINT A
----

Ausgabe:

[source]
----
10
25
----

Der alte Wert wird dabei überschrieben.

=== Der Inhalt einer Variablen kann berechnet werden

Besonders interessant wird es, wenn eine Variable mit ihrem eigenen Inhalt verändert wird.

[source,basic]
----
A=10
A=A+1

PRINT A
----

Ausgabe:

[source]
----
11
----

Schauen wir uns die zweite Zeile genauer an:

[source,basic]
----
A=A+1
----

Zuerst berechnet MMBasic die rechte Seite:

[source,basic]
----
10+1
----

Danach wird das Ergebnis wieder in `A` gespeichert.

=== Zähler erstellen

Auf diese Weise kann ein einfacher indexterm:[Zähler] Zähler aufgebaut werden.

[source,basic]
----
A=0

A=A+1
PRINT A

A=A+1
PRINT A

A=A+1
PRINT A
----

Ausgabe:

[source]
----
1
2
3
----
