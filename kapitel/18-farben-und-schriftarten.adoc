== Farben und Schriftarten

image::bilder/18_farben_und_schriftarten.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* Farben in MMBasic zu verwenden
* die Funktion `RGB()` einzusetzen
* Vorder- und Hintergrundfarben festzulegen
* verschiedene Schriftarten auszuwählen
* Schriftgrößen zu verändern
* die Breite und Höhe der aktuellen Schrift zu ermitteln
* Texte abhängig von Bildschirm- und Schriftgröße zu positionieren
* farbige Ausgaben übersichtlich in mehreren Bereichen des Bildschirms anzuordnen

Am Ende des Kapitels kannst du farbige Bildschirmausgaben gestalten,
verschiedene Schriftarten verwenden und Texte passend zur aktuellen
Bildschirm- und Schriftgröße positionieren.

=== Farben in MMBasic

MMBasic verwendet ein modernes Farbsystem mit indexterm:[Grafik,Farbtiefe]indexterm:[Farbtiefe] 24 Bit Farbtiefe.

Jede Farbe setzt sich aus den Anteilen für:

* Rot
* Grün
* Blau

zusammen.

Daher stammt auch die Bezeichnung indexterm:[Farben,RGB] RGB.

=== Farben mit RGB() erzeugen

Die Funktion RGB() erwartet drei Werte zwischen 0 und 255.

[source,basic]
----
RGB(Rot, Gruen, Blau)
----

Beispiele:

[source,basic]
----
RGB(255,0,0)
RGB(0,255,0)
RGB(0,0,255)
----

erzeugen:

* Rot
* Grün
* Blau

=== Farbkonstanten verwenden

Häufig verwendete Farben können direkt über indexterm:[Farben,Farbkonstanten]indexterm:[Farbkonstanten] Farbkonstanten angegeben werden.

[source,basic]
----
RGB(RED)
RGB(GREEN)
RGB(BLUE)
RGB(YELLOW)
RGB(CYAN)
RGB(MAGENTA)
RGB(WHITE)
RGB(BLACK)
----

Dadurch werden Programme leichter lesbar.

=== Vorder- und Hintergrundfarbe

Mit dem Befehl indexterm:[Grafikbefehle,COLOUR]indexterm:[COLOUR] `COLOUR` werden die Standardfarben festgelegt.

[source,basic]
----
COLOUR RGB(YELLOW), RGB(BLUE)
----

Dabei bedeutet:

* Gelb = Vordergrundfarbe
* Blau = Hintergrundfarbe

Alle folgenden Textausgaben verwenden diese Farben.

[source,basic]
----
CLS

COLOUR RGB(YELLOW), RGB(BLUE)

PRINT "Hallo MMBasic"
----

=== Der Bildschirmhintergrund

Mit indexterm:[Grafikbefehle,CLS]indexterm:[CLS] `CLS` wird der Bildschirm gelöscht.

Ohne Parameter wird die aktuelle Hintergrundfarbe verwendet.

[source,basic]
----
CLS
----

Es kann aber auch direkt eine Farbe angegeben werden.

[source,basic]
----
CLS RGB(BLACK)
----

=== Ein kleines Farbexperiment

[source,basic]
----
CLS RGB(BLACK)

COLOUR RGB(YELLOW), RGB(BLACK)

PRINT "Gelber Text"

COLOUR RGB(CYAN), RGB(BLACK)

PRINT "Cyanfarbener Text"

COLOUR RGB(RED), RGB(BLACK)

PRINT "Roter Text"
----

Probiere verschiedene Farbkombinationen aus.

=== Schriftarten

MMBasic enthält bereits mehrere eingebaute indexterm:[Grafik,Schriftarten]indexterm:[Schriftarten] Schriftarten.

Jede Schrift besitzt eine andere Größe.

Die Standard-Schrift ist Schriftart 1.

=== Schriftart auswählen

Mit indexterm:[Grafikbefehle,FONT]indexterm:[FONT] `FONT` wird die gewünschte Schriftart ausgewählt.

[source,basic]
----
FONT 1
PRINT "Schriftart 1"

FONT 2
PRINT "Schriftart 2"

FONT 3
PRINT "Schriftart 3"
----

=== Die wichtigsten Schriftarten

[cols="1,3"]
|===
|Font |Beschreibung

|1
|Standardschrift

|2
|Mittlere Schrift

|3
|Große Schrift

|5
|Sehr große Schrift

|6
|Große Ziffern
|===

=== Schriftgröße ausprobieren

[source,basic]
----
CLS

FONT 1
PRINT "Kleine Schrift"

FONT 2
PRINT "Mittlere Schrift"

FONT 3
PRINT "Grosse Schrift"

FONT 5
PRINT "Sehr grosse Schrift"
----

=== Große Zahlen darstellen

Für Messwerte oder Uhren eignet sich Font 6 besonders gut.

[source,basic]
----
CLS

FONT 6

PRINT "12:45"
----

=== Informationen zur aktuellen Schrift

Die Breite und Höhe der aktuellen Schrift können abgefragt werden.

[source,basic]
----
PRINT MM.INFO(FONTWIDTH)
PRINT MM.INFO(FONTHEIGHT)
----

Beispiel:

[source]
----
16
24
----

Die Werte hängen von der gewählten Schriftart und vom verwendeten Grafikmodus ab.

=== Ein digitales Display

Das folgende Programm simuliert eine einfache Digitalanzeige.

[source,basic]
----
CLS RGB(BLACK)

COLOUR RGB(GREEN), RGB(BLACK)

FONT 6

PRINT TIME$
----

Je nach System wird die aktuelle Uhrzeit in großen Ziffern dargestellt.

=== Praxisbeispiel: Eine Farb- und Schriftmustertafel

Wir haben nun Farben, Vorder- und Hintergrundfarben sowie verschiedene
Schriftarten kennengelernt.

Zum Abschluss erstellen wir eine kleine Farb- und Schriftmustertafel, die
mehrere Möglichkeiten auf einer Bildschirmseite zusammenfasst.

Dabei wollen wir die verfügbare Bildschirmbreite möglichst gut ausnutzen:
Die vordefinierten Farben erscheinen links, selbst gemischte RGB-Farben
rechts. Darunter zeigen wir verschiedene Schriftarten.

Das Beispiel greift damit auch Techniken aus den vorherigen Kapiteln wieder
auf. Die Positionen der Texte werden nicht mit festen X-Koordinaten
festgelegt, sondern aus der aktuellen Bildschirm- und Schriftgröße
berechnet.

==== Zwei Spalten auf dem Bildschirm

Für unsere Mustertafel benötigen wir eine linke und eine rechte Spalte.

Texte in der linken Spalte beginnen immer am linken Bildschirmrand. Dafür
schreiben wir eine kleine Unterroutine:

[source,basic]
----
Sub PrintLeft(ypos, txt$)
  Print @(0,ypos) txt$
End Sub
----

Die X-Koordinate ist immer `0`. Lediglich die Y-Koordinate und der
auszugebende Text werden beim Aufruf übergeben.

Zum Beispiel:

[source,basic]
----
PrintLeft(Y, "Vordefinierte Farben:")
----

Interessanter wird die rechte Spalte.

Wir könnten dafür eine feste X-Koordinate verwenden:

[source,basic]
----
Print @(200,Y) "Eigene RGB-Farben:"
----

Das würde jedoch nur bei einer bestimmten Bildschirmbreite zuverlässig
funktionieren.

Stattdessen soll der Text immer am rechten Bildschirmrand ausgerichtet
werden.

==== Die rechte Textposition berechnen

Aus dem vorherigen Kapitel kennen wir bereits `MM.HRES`. Damit erhalten wir
die Breite des aktuellen Grafikbereichs.

Die Anzahl der Zeichen eines Textes liefert `LEN()`:

[source,basic]
----
Len(txt$)
----

Mit `MM.Info(FONTWIDTH)` erfahren wir, wie breit ein Zeichen des aktuellen
Fonts in Pixeln ist.

Die Breite des gesamten Textes können wir deshalb berechnen mit:

[source,basic]
----
Len(txt$)*MM.Info(FONTWIDTH)
----

Ziehen wir diese Textbreite von der Bildschirmbreite ab, erhalten wir die
X-Koordinate, an der der Text beginnen muss, damit seine rechte Kante am
rechten Bildschirmrand liegt.

Da wir diesen berechneten Wert nur für die Ausgabe benötigen, brauchen wir
dafür nicht einmal eine zusätzliche Variable. Wir können die Berechnung
direkt als X-Koordinate in `PRINT @()` einsetzen:

[source,basic]
----
Print @(MM.HRES-Len(txt$)*MM.Info(FONTWIDTH),ypos) txt$
----

Daraus entsteht unsere zweite Unterroutine:

[source,basic]
----
Sub PrintRight(ypos, txt$)
  Print @(MM.HRES-Len(txt$)*MM.Info(FONTWIDTH),ypos) txt$
End Sub
----

Ein Aufruf wie

[source,basic]
----
PrintRight(Y, "Eigene RGB-Farben:")
----

positioniert den Text damit automatisch am rechten Bildschirmrand.

[NOTE]
====
Die Position hängt nicht von einer fest eingetragenen Bildschirmbreite ab.
`MM.HRES` und `MM.Info(FONTWIDTH)` liefern die Werte des aktuell verwendeten
Grafikmodus und Fonts.

Dadurch passt sich die Berechnung an die aktuelle Darstellung an.
====

==== Die Zeilenpositionen berechnen

Auch für die vertikalen Abstände verwenden wir keine fest eingetragenen
Pixelwerte.

Zunächst bestimmen wir die Höhe eines Zeichens:

[source,basic]
----
DY=MM.Info(FONTHEIGHT)
----

Unsere erste Ausgabezeile berechnen wir mit:

[source,basic]
----
Y=MM.Info(FONTHEIGHT)*3
----

Weitere Zeilen können wir anschließend relativ zu dieser Position ausgeben:

[source,basic]
----
PrintLeft(Y, "WHITE")
PrintLeft(Y+DY, "RED")
PrintLeft(Y+DY*2, "GREEN")
----

Ändert sich die Höhe des verwendeten Fonts, passen sich damit auch die
Zeilenabstände an.

==== Die vordefinierten Farben

In der linken Spalte zeigen wir zunächst einige der vordefinierten
Farbkonstanten von MMBasic.

Dazu ändern wir vor jeder Ausgabe die Vordergrundfarbe:

[source,basic]
----
Colour RGB(WHITE),RGB(BLACK)
PrintLeft(Y, "WHITE")

Colour RGB(RED),RGB(BLACK)
PrintLeft(Y+DY, "RED")

Colour RGB(GREEN),RGB(BLACK)
PrintLeft(Y+DY*2, "GREEN")

Colour RGB(BLUE),RGB(BLACK)
PrintLeft(Y+DY*3, "BLUE")
----

Auf die gleiche Weise folgen `YELLOW`, `CYAN` und `MAGENTA`.

Der Hintergrund bleibt bei allen Ausgaben schwarz.

==== Eigene RGB-Farben

In der rechten Spalte verwenden wir dagegen selbst zusammengestellte
RGB-Farben.

Beispielsweise erzeugen wir Orange mit:

[source,basic]
----
Colour RGB(255,128,0),RGB(BLACK)
PrintRight(Y, "ORANGE RGB(255,128,0)")
----

Neben dem Namen der Farbe geben wir auch gleich die verwendeten RGB-Werte
aus. Dadurch wird unsere Mustertafel gleichzeitig zu einer kleinen
Farbreferenz.

Weitere Beispiele sind:

[source,basic]
----
Colour RGB(128,255,0),RGB(BLACK)
PrintRight(Y+DY, "HELLGRUEN RGB(128,255,0)")

Colour RGB(255,128,192),RGB(BLACK)
PrintRight(Y+DY*2, "ROSA RGB(255,128,192)")

Colour RGB(128,128,255),RGB(BLACK)
PrintRight(Y+DY*3, "HELLBLAU RGB(128,128,255)")

Colour RGB(128,128,128),RGB(BLACK)
PrintRight(Y+DY*4, "GRAU RGB(128,128,128)")
----

So können wir die Wirkung verschiedener Rot-, Grün- und Blauanteile direkt
miteinander vergleichen.

==== Verschiedene Schriftarten

Unterhalb der Farbtabelle zeigen wir zusätzlich einige der eingebauten
Schriftarten.

Zunächst wechseln wir wieder zu weißer Schrift:

[source,basic]
----
Colour RGB(WHITE),RGB(BLACK)
----

Dann geben wir Beispiele mit verschiedenen Fonts aus:

[source,basic]
----
Font 1
PrintLeft(Y, "Font 1 - Standardschrift")

Y=Y+MM.Info(FONTHEIGHT)

Font 2
PrintLeft(Y, "Font 2")

Y=Y+MM.Info(FONTHEIGHT)

Font 3
PrintLeft(Y, "Font 3")
----

Beachte, dass `MM.Info(FONTHEIGHT)` jeweils nach dem Wechsel des Fonts
ausgewertet wird. Dadurch wird für die nächste Ausgabe die Höhe des gerade
aktiven Fonts berücksichtigt.

Am Ende stellen wir wieder `FONT 1` sowie weiße Schrift auf schwarzem
Hintergrund ein.

==== Das vollständige Programm

Nun setzen wir alle Teile zu unserer Farb- und Schriftmustertafel zusammen:

[source,basic]
----
CLS RGB(BLACK)
Font 1
Colour RGB(WHITE),RGB(BLACK)
Print "MMBasic Farb- und Schriftmustertafel"
Print

' ------------------------------------------------------------
' Positionen fuer die beiden Spalten berechnen
' ------------------------------------------------------------
Y=MM.Info(FONTHEIGHT)*3
DY=MM.Info(FONTHEIGHT)

' ------------------------------------------------------------
' Ueberschriften
' ------------------------------------------------------------
Colour RGB(WHITE),RGB(BLACK)
PrintLeft(Y,"Vordefinierte Farben:")
PrintRight(Y,"Eigene RGB-Farben:")
Y=Y+DY*2

' ------------------------------------------------------------
' Vordefinierte Farben - linke Spalte
' ------------------------------------------------------------
Colour RGB(WHITE),RGB(BLACK)
PrintLeft(Y, "WHITE")

Colour RGB(RED),RGB(BLACK)
PrintLeft(Y+DY, "RED")

Colour RGB(GREEN),RGB(BLACK)
PrintLeft(Y+DY*2, "GREEN")

Colour RGB(BLUE),RGB(BLACK)
PrintLeft(Y+DY*3, "BLUE")

Colour RGB(YELLOW),RGB(BLACK)
PrintLeft(Y+DY*4, "YELLOW")

Colour RGB(CYAN),RGB(BLACK)
PrintLeft(Y+DY*5, "CYAN")

Colour RGB(MAGENTA),RGB(BLACK)
PrintLeft(Y+DY*6, "MAGENTA")

' ------------------------------------------------------------
' Selbst gemischte Farben - rechte Spalte
' ------------------------------------------------------------
Colour RGB(255,128,0),RGB(BLACK)
PrintRight(Y, "ORANGE RGB(255,128,0)")

Colour RGB(128,255,0),RGB(BLACK)
PrintRight(Y+DY, "HELLGRUEN RGB(128,255,0)")

Colour RGB(255,128,192),RGB(BLACK)
PrintRight(Y+DY*2, "ROSA RGB(255,128,192)")

Colour RGB(128,128,255),RGB(BLACK)
PrintRight(Y+DY*3, "HELLBLAU RGB(128,128,255)")

Colour RGB(128,128,128),RGB(BLACK)
PrintRight(Y+DY*4, "GRAU RGB(128,128,128)")

' ------------------------------------------------------------
' Verschiedene Schriftarten
' ------------------------------------------------------------
Y=Y+DY*8
Colour RGB(WHITE),RGB(BLACK)

Font 1
PrintLeft(Y, "Schriftarten:")

Y=Y+MM.Info(FONTHEIGHT)*2

Font 1
PrintLeft(Y, "Font 1 - Standardschrift")

Y=Y+MM.Info(FONTHEIGHT)

Font 2
PrintLeft(Y, "Font 2")

Y=Y+MM.Info(FONTHEIGHT)

Font 3
PrintLeft(Y, "Font 3")

' Standardschrift und Farben wiederherstellen
Font 1
Colour RGB(WHITE),RGB(BLACK)

End

Sub PrintLeft(ypos, txt$)
  Print @(0,ypos) txt$
End Sub

Sub PrintRight(ypos, txt$)
  Print @(MM.HRES-Len(txt$)*MM.Info(FONTWIDTH),ypos) txt$
End Sub
----

Die Mustertafel zeigt auf einen Blick vordefinierte Farben, einige selbst
gemischte RGB-Farben und verschiedene Schriftarten.

Gleichzeitig haben wir Techniken aus den vorherigen Kapiteln wiederverwendet:
Unterprogramme strukturieren den Programmcode, `LEN()` bestimmt die
Textlänge und die Systeminformationen `MM.HRES`, `MM.Info(FONTWIDTH)` und
`MM.Info(FONTHEIGHT)` helfen uns dabei, die Ausgabe passend zum aktuellen
Grafikmodus zu positionieren.

[TIP]
====
Eine solche Mustertafel kann bei eigenen Programmen sehr nützlich sein.
Probiere verschiedene RGB-Werte und Fonts aus und vergleiche direkt auf
deinem Bildschirm, welche Kombinationen gut lesbar sind.
====
