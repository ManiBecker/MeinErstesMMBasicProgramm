== Zufallszahlen

=== Das lernst du

In diesem Kapitel lernst du:

* wie Zufallszahlen erzeugt werden
* wie die Funktion `RND` verwendet wird
* wie Zufallszahlen auf einen gewünschten Bereich angepasst werden

* warum `RANDOMIZE` auf dem RP2350 nicht benötigt wird

Am Ende des Kapitels kannst du Würfel, Münzwürfe und kleine Spiele programmieren.

=== Warum Zufallszahlen wichtig sind

indexterm:[Zufallszahlen]

Viele Programme benötigen Zufallszahlen.

Zum Beispiel:

* Spiele
* Quizprogramme
* Simulationen
* Würfel
* Lottozahlen

indexterm:[Zufallsfunktionen,RND]
indexterm:[RND]

MMBasic stellt dafür die Funktion `RND` bereit.

=== Eine Zufallszahl erzeugen

Gib folgendes Programm ein:

[source,basic]
----
PRINT RND
----

Bei jeder Ausführung erscheint eine andere Zahl.

Zum Beispiel:

[source]
----
0.38142
----

oder

[source]
----
0.92471
----

=== Zufallszahlen mehrfach erzeugen

Mit einer Schleife können mehrere Zufallszahlen ausgegeben werden.

[source,basic]
----
FOR I=1 TO 10
  PRINT RND
NEXT I
----

=== Einen Würfel simulieren

Ein Würfel besitzt die Werte 1 bis 6.

indexterm:[Mathematische Funktionen,INT]
indexterm:[INT]

[source,basic]
----
PRINT INT(RND*6)+1
----

Mögliche Ausgabe:

[source]
----
4
----

=== Mehrfach würfeln

[source,basic]
----
FOR I=1 TO 10
  PRINT INT(RND*6)+1
NEXT I
----

=== Münze werfen

[source,basic]
----
IF INT(RND*2)=0 THEN
  PRINT "Kopf"
ELSE
  PRINT "Zahl"
ENDIF
----

=== Lottozahlen erzeugen

[source,basic]
----
FOR I=1 TO 6
  PRINT INT(RND*49)+1
NEXT I
----

Hinweis:

Die Zahlen können mehrfach auftreten. Eine vollständige Lotto-Simulation werden wir später erstellen.

=== Ein Ratespiel

[source,basic]
----
GEHEIM=INT(RND*10)+1

PRINT "Rate eine Zahl von 1 bis 10"

INPUT TIPP

IF TIPP=GEHEIM THEN
  PRINT "Richtig!"
ELSE
  PRINT "Leider falsch."
ENDIF
----

=== RANDOMIZE – unterschiedliche Zufallsfolgen

Auf einem RP2040 erzeugt `RND` sogenannte
indexterm:[Pseudozufallszahlen] *Pseudozufallszahlen*. Dabei wird eine
Zahlenfolge berechnet, die zufällig erscheint.

Nach dem Einschalten beginnt der Zufallszahlengenerator jedoch mit demselben
Startwert. Dadurch kann bei jedem Programmstart dieselbe Folge von
Zufallszahlen entstehen.

Mit indexterm:[RANDOMIZE] `RANDOMIZE` kann ein anderer Startwert festgelegt
werden. Als Startwert eignet sich beispielsweise `TIMER`:

[source,basic]
----
RANDOMIZE TIMER

FOR I=1 TO 5
  PRINT RND
NEXT I
----

Da sich der Wert von `TIMER` verändert, beginnt der Zufallszahlengenerator
nicht immer mit derselben Zahlenfolge.

[NOTE]
====
Auf dem RP2350 ist `RANDOMIZE` nicht erforderlich. Dieser Mikrocontroller
besitzt einen Hardware-Zufallszahlengenerator und erzeugt mit `RND` echte
Zufallszahlen. Der Befehl `RANDOMIZE` hat auf dem RP2350 deshalb keine
Wirkung.

Der RP2040 besitzt diesen Hardware-Zufallszahlengenerator nicht. Dort ist
`RANDOMIZE` sinnvoll, wenn bei jedem Programmstart eine andere Folge von
Pseudozufallszahlen gewünscht ist.
====

[TIP]
====
MMBasic bietet mit `MATH(RAND)` außerdem einen Zufallszahlengenerator auf
Basis des Mersenne-Twister-Algorithmus. Dieser kann mit `MATH RANDOMIZE`
initialisiert werden.

Für unsere ersten Programme verwenden wir zunächst `RND`.
====
