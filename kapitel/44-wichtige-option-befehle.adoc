== Wichtige OPTION-Befehle

image::bilder/44_optionen.jpg[align=center]

=== Das lernst du

In diesem Kapitel lernst du:

* was `OPTION`-Befehle sind
* den Unterschied zwischen temporären und permanenten Optionen
* warum manche OPTION-Einstellungen vor dem Start eines Programms vorgenommen werden müssen
* wichtige `OPTION`-Befehle für Programme und die Systemkonfiguration einzusetzen
* Bildschirmauflösung und CPU-Takt zu konfigurieren
* Tastaturlayout und Tastenwiederholung einzustellen
* die aktuelle Konfiguration mit `OPTION LIST` zu untersuchen
* typische Fehler beim Umgang mit Optionen zu vermeiden

Am Ende des Kapitels kennst du einige der wichtigsten Möglichkeiten, das Verhalten von MMBasic an deine Bedürfnisse anzupassen.

=== Was sind OPTION-Befehle?

Bisher haben wir überwiegend Befehle kennengelernt, die unmittelbar etwas ausführen:

[source,basic]
----
PRINT "Hallo Welt"
CLS
LINE 0,0,100,100
----

indexterm:[OPTION] `OPTION`-Befehle funktionieren etwas anders. Sie verändern Einstellungen von MMBasic und können sowohl das Verhalten eines BASIC-Programms als auch die Konfiguration des PicoMite beeinflussen.

Dabei ist eine wichtige Unterscheidung zu beachten:

* indexterm:[Temporäre Optionen] *Temporäre bzw. programmbezogene Optionen* gelten nur vorübergehend und werden beispielsweise beim Start eines Programms oder beim Neustart wieder auf ihre Standardwerte gesetzt.
* indexterm:[Temporäre Optionen] *Permanente Optionen* werden im nichtflüchtigen Speicher abgelegt und nach einem Neustart automatisch wiederhergestellt.

Viele permanente `OPTION`-Befehle können einen Neustart der PicoMite-Firmware auslösen. Das im Programmspeicher befindliche BASIC-Programm geht dabei nicht verloren.

=== Warum müssen manche OPTION-Einstellungen vorher vorgenommen werden?

Vielleicht hast du dich schon gefragt, warum bestimmte OPTION-Einstellungen nicht einfach am Anfang eines BASIC-Programms stehen können.

Der Grund liegt im Unterschied zwischen programmbezogenen Optionen und den Grundeinstellungen der MMBasic-Umgebung.

Programmbezogene Optionen beeinflussen nur die Ausführung eines BASIC-Programms. Sie können deshalb direkt im Programm stehen. Beispiele dafür sind OPTION EXPLICIT, OPTION DEFAULT und OPTION BASE.

Andere OPTION-Befehle legen dagegen Grundeinstellungen der MMBasic-Umgebung oder der verwendeten Hardware fest. Damit wird beispielsweise bestimmt, welche Bildschirmkonfiguration verwendet wird, welche Pins für bestimmte Funktionen reserviert sind oder wie bestimmte Hardware-Komponenten genutzt werden.

Viele dieser Einstellungen werden dauerhaft gespeichert und beim nächsten Start von MMBasic wieder verwendet. Manche beeinflussen Ressourcen oder Hardware-Funktionen, die MMBasic bereits beim Start einrichtet. Eine Änderung kann deshalb einen Neustart erforderlich machen.

[NOTE]

Eine einfache Unterscheidung hilft dabei:

Programmbezogene OPTION-Befehle legen fest, wie dein BASIC-Programm ausgeführt wird.
Permanente OPTION-Befehle legen Grundeinstellungen fest, in welcher Umgebung dein BASIC-Programm ausgeführt wird.
Deshalb können programmbezogene Optionen im BASIC-Programm stehen, während grundlegende System- und Hardwareoptionen normalerweise vorher an der MMBasic-Eingabeaufforderung eingestellt werden.

=== Aktuelle Einstellungen anzeigen

Mit indexterm:[OPTION LIST] `OPTION LIST`:

[source,basic]
----
OPTION LIST
----

kannst du die permanenten Optionen anzeigen, die gegenüber ihren Standardwerten geändert wurden.

Zusätzlich zeigt `OPTION LIST` die Versionsnummer und die geladene Firmware an.

[NOTE]
====
`OPTION LIST` muss an der MMBasic-Eingabeaufforderung ausgeführt werden. Der Befehl kann nicht innerhalb eines BASIC-Programms verwendet werden.
====

=== Programmbezogene Optionen

Einige `OPTION`-Befehle beeinflussen unmittelbar die Ausführung eines BASIC-Programms. Dazu gehören beispielsweise `OPTION EXPLICIT`, `OPTION DEFAULT` und `OPTION BASE`.

Diese Einstellungen sind nicht dauerhaft gespeichert.

=== OPTION EXPLICIT

Eine besonders nützliche Option für Programmierer ist:

[source,basic]
----
OPTION EXPLICIT
----

Ist diese Option aktiv, müssen alle Variablen vor ihrer Verwendung ausdrücklich mit `DIM`, `LOCAL` oder `STATIC` deklariert werden.

Beispiel:

[source,basic]
----
OPTION EXPLICIT

DIM punkte

punkte = 100
----

Wird versehentlich eine andere Variable verwendet:

[source,basic]
----
punkt = 100
----

meldet MMBasic einen Fehler, weil `punkt` nicht deklariert wurde.

Ohne `OPTION EXPLICIT` würde MMBasic automatisch eine neue Variable anlegen.

`OPTION EXPLICIT` muss vor der ersten Verwendung einer Variablen stehen. Beim Start eines Programms ist die Option standardmäßig deaktiviert und muss deshalb bei Bedarf im Programm selbst aktiviert werden.

=== Warum OPTION EXPLICIT sinnvoll ist

Betrachten wir folgendes Beispiel:

[source,basic]
----
punkte = punkte + 10
PRINT punkte
----

Vertippt man sich:

[source,basic]
----
punkte = punkt + 10
----

kann ohne `OPTION EXPLICIT` unbemerkt eine neue Variable mit dem Namen `punkt` entstehen.

Solche Fehler sind oft schwer zu finden. `OPTION EXPLICIT` hilft dabei, sie frühzeitig zu erkennen.

=== OPTION DEFAULT

Mit indexterm:[OPTION DEFAULT] `OPTION DEFAULT` wird festgelegt, welchen Datentyp eine Variable erhält, wenn kein Typ ausdrücklich angegeben wurde.

Mögliche Einstellungen sind indexterm:[Datentypen,Standard-Datentyp]indexterm:[Standard-Datentyp] verschiedene Standard-Datentypen:

[source,basic]
----
OPTION DEFAULT FLOAT
OPTION DEFAULT INTEGER
OPTION DEFAULT STRING
OPTION DEFAULT NONE
----

Beim Start eines Programms wird die Einstellung standardmäßig auf `FLOAT` gesetzt.

=== OPTION DEFAULT FLOAT

[source,basic]
----
OPTION DEFAULT FLOAT
----

Variablen ohne ausdrücklich angegebenen Typ werden als Fließkommazahlen behandelt.

Dies ist die Standardeinstellung von MMBasic und dient der Kompatibilität mit Microsoft BASIC und früheren MMBasic-Versionen.

=== OPTION DEFAULT INTEGER

[source,basic]
----
OPTION DEFAULT INTEGER
----

Variablen ohne ausdrücklich angegebenen Typ werden als Ganzzahlen behandelt.

=== OPTION DEFAULT STRING

[source,basic]
----
OPTION DEFAULT STRING
----

Variablen ohne ausdrücklich angegebenen Typ werden als Zeichenketten behandelt.

=== OPTION DEFAULT NONE

Die strengste Variante ist:

[source,basic]
----
OPTION DEFAULT NONE
----

Nun muss für jede Variable ein Datentyp ausdrücklich angegeben werden. Andernfalls meldet MMBasic:

[source]
----
Variable type not specified
----

Beispiel:

[source,basic]
----
DIM name$
DIM punkte%
DIM temperatur!
----

Die Typzeichen `$`, `%` und `!` legen dabei den jeweiligen Datentyp fest.

=== OPTION EXPLICIT und OPTION DEFAULT NONE

Die beiden Optionen prüfen unterschiedliche Dinge:

* `OPTION EXPLICIT` verlangt, dass Variablen deklariert werden.
* `OPTION DEFAULT NONE` verlangt, dass ihr Datentyp ausdrücklich festgelegt wird.

Beide Optionen können miteinander kombiniert werden:

[source,basic]
----
OPTION EXPLICIT
OPTION DEFAULT NONE

DIM punkte%
DIM temperatur!
DIM name$
----

Dadurch können viele Schreib- und Typfehler bereits während der Entwicklung erkannt werden.

=== OPTION BASE

Mit `OPTION BASE` wird festgelegt, bei welchem Index Arrays beginnen.

Standard ist:

[source,basic]
----
OPTION BASE 0
----

Beispiel:

[source,basic]
----
DIM zahlen(10)
----

Die Elemente reichen dann von:

[source]
----
zahlen(0)
bis
zahlen(10)
----

Alternativ kann festgelegt werden:

[source,basic]
----
OPTION BASE 1
----

Dann beginnt das Array bei `zahlen(1)`.

[IMPORTANT]
====
`OPTION BASE` muss verwendet werden, bevor das erste Array deklariert wird. Nach dem Einschalten des PicoMite ist der Standardwert wieder `0`.
====

[TIP]
====
In diesem Tutorial verwenden wir grundsätzlich `OPTION BASE 0`.
====

=== Permanente Optionen

Andere `OPTION`-Befehle verändern Einstellungen der MMBasic-Arbeitsumgebung oder der Hardwarekonfiguration und werden dauerhaft gespeichert.

Dazu gehören beispielsweise `OPTION TAB` und `OPTION COLOURCODE`. Auch `OPTION CPUSPEED` gehört bei den PicoMite-Versionen, die diesen Befehl unterstützen, zu den permanenten Optionen.

=== OPTION TAB

indexterm:[OPTION TAB] Diese Option legt den Abstand der Tabulatortaste fest.

Mögliche Werte sind:

[source,basic]
----
OPTION TAB 2
OPTION TAB 3
OPTION TAB 4
OPTION TAB 8
----

Beispielsweise stellt:

[source,basic]
----
OPTION TAB 4
----

den Tabulatorabstand auf vier Zeichenpositionen ein.

Der Standardwert ist `2`. Die Einstellung wird dauerhaft gespeichert.

=== OPTION COLOURCODE

Der eingebaute Editor kann BASIC-Programme farbig darstellen.

Aktivieren:

[source,basic]
----
OPTION COLOURCODE ON
----

Deaktivieren:

[source,basic]
----
OPTION COLOURCODE OFF
----

Schlüsselwörter werden beispielsweise in Cyan und Kommentare in Gelb dargestellt. Die Standardeinstellung ist `OFF`.

Alternativ akzeptiert MMBasic auch die amerikanische Schreibweise `OPTION COLORCODE`.

Die Farbdarstellung funktioniert bei VGA- und HDMI-Ausgabe sowie über die serielle Konsole mit einem VT100-kompatiblen Terminalprogramm.

[NOTE]
====
`OPTION COLOURCODE` ist eine permanente Option und muss an der MMBasic-Eingabeaufforderung ausgeführt werden. Innerhalb eines BASIC-Programms ist der Befehl nicht zulässig.
====

=== CPU-Takt bei VGA und HDMI

Bei den VGA- und HDMI-Versionen wird die CPU-Taktfrequenz nicht mit
`OPTION CPUSPEED` eingestellt. Hier hängt sie mit der verwendeten
Videoauflösung zusammen.

Dafür gibt es indexterm:[OPTION RESOLUTION] `OPTION RESOLUTION`:

[source,basic]
----
OPTION RESOLUTION nn [,cpuspeedinKhz]
----

Bei einer Auflösung von 640 × 480 nennt das PicoMite-Handbuch beispielsweise
CPU-Taktfrequenzen von 252 MHz, 315 MHz oder 378 MHz, abhängig von der
gewünschten Bildwiederholfrequenz.

Das erklärt auch, warum beispielsweise:

[source,basic]
----
PRINT MM.INFO$(CPUSPEED)
----

auf einem PicoMite HDMI/USB einen Wert wie:

[source]
----
252000000
----

liefern kann. `MM.INFO$(CPUSPEED)` gibt die CPU-Taktfrequenz dabei in Hz
zurück.

==== Bildwiederholrate und Monitor-Kompatibilität

Die mit `OPTION RESOLUTION` gewählte CPU-Taktfrequenz beeinflusst bei der
Videoausgabe auch die Bildwiederholrate.

Das kann in der Praxis eine wichtige Rolle spielen. Beim Test des
Pico Computer 3 lieferte beispielsweise folgende Einstellung an einem
Monitor zunächst kein Bild:

[source,basic]
----
OPTION RESOLUTION 640,315000
----

Ein anderer Monitor konnte diese Einstellung dagegen problemlos darstellen.
Mit dieser Einstellung wird eine Bildwiederholrate von 75 Hz verwendet.

Durch die Umstellung auf:

[source,basic]
----
OPTION RESOLUTION 640,252000
----

wurde die Bildwiederholrate auf 60 Hz reduziert. Damit funktionierte die
Ausgabe auch am zuvor problematischen Monitor.

[NOTE]
====
Wenn ein PicoMite mit VGA- oder HDMI-Ausgabe an einem Monitor kein Bild
liefert, muss deshalb nicht unbedingt ein Hardwarefehler vorliegen.

Prüfe auch die mit `OPTION RESOLUTION` eingestellte Auflösung und
Bildwiederholrate. Eine Einstellung mit 60 Hz kann bei Monitoren mit
eingeschränkter Unterstützung verschiedener Bildwiederholraten die
kompatiblere Wahl sein.
====

=== Tastatur konfigurieren

MMBasic geht standardmäßig von einer Tastatur mit US-amerikanischem Layout
aus.

Mit indexterm:[OPTION KEYBOARD] `OPTION KEYBOARD` kann ein anderes
Tastaturlayout eingestellt werden.

Die grundlegende Syntax lautet:

[source,basic]
----
OPTION KEYBOARD language
----

Für eine deutsche Tastatur verwenden wir:

[source,basic]
----
OPTION KEYBOARD GR
----

`GR` steht dabei für das deutsche Tastaturlayout.

Weitere unterstützte Tastaturlayouts sind beispielsweise `US`, `UK`, `FR`,
`BE`, `IT`, `BR` und `ES`.

[NOTE]
====
Bei nicht-amerikanischen Tastaturlayouts können zwar zusätzliche
Sondertasten der jeweiligen Tastatur berücksichtigt werden. Nicht alle
zugehörigen Sonderzeichen sind jedoch in den Standardfonts des PicoMite
enthalten. In diesem Fall wird stattdessen ein entsprechendes
ASCII-Zeichen dargestellt.
====

==== Caps Lock, Num Lock und Tastenwiederholung

Bei der Konfiguration der Tastatur können weitere Parameter angegeben werden:

[source,basic]
----
OPTION KEYBOARD nn [,capslock] [,numlock] [,repeatstart] [,repeatrate]
----

`capslock` und `numlock` bestimmen den anfänglichen Zustand der beiden
Tastaturfunktionen.

Die Standardwerte sind:

[cols="2,1,3"]
|===
|Parameter |Standard |Bedeutung

|`capslock`
|`0`
|Caps Lock ausgeschaltet

|`numlock`
|`1`
|Num Lock eingeschaltet
|===

Die beiden weiteren Parameter bestimmen die Tastenwiederholung.

`repeatstart` legt fest, wie lange eine Taste gedrückt gehalten werden muss,
bevor die automatische Wiederholung beginnt.

`repeatrate` bestimmt anschließend den zeitlichen Abstand zwischen den
einzelnen Wiederholungen.

Bei einer USB-Tastatur werden beide Zeiten in Millisekunden angegeben:

[cols="2,2,3"]
|===
|Parameter |Bereich |Bedeutung

|`repeatstart`
|100–2000 ms
|Verzögerung bis zur ersten Wiederholung

|`repeatrate`
|25–2000 ms
|Abstand zwischen den weiteren Wiederholungen
|===

Eine mögliche Einstellung für eine deutsche USB-Tastatur wäre beispielsweise:

[source,basic]
----
OPTION KEYBOARD GR,0,1,250,50
----

Damit verwenden wir das deutsche Tastaturlayout, Caps Lock ist zunächst
ausgeschaltet und Num Lock eingeschaltet. Eine gehaltene Taste beginnt nach
250 ms mit der Wiederholung und wird anschließend alle 50 ms erneut gemeldet.

[NOTE]
====
Bei einer PS/2-Tastatur werden für `repeatstart` und `repeatrate` keine
Millisekundenwerte angegeben. Stattdessen gelten die in der
PS/2-Spezifikation definierten Einstellwerte.

Der Standardwert für `repeatstart` ist `1`, entsprechend 500 ms. Für
`repeatrate` ist der Standardwert `12`, entsprechend 100 ms.
====

==== Wiederholrate einer USB-Tastatur ändern

Bei einer bereits konfigurierten USB-Tastatur kann die Tastenwiederholung
auch separat geändert werden.

Dafür gibt es
indexterm:[OPTION KEYBOARD REPEAT] `OPTION KEYBOARD REPEAT`:

[source,basic]
----
OPTION KEYBOARD REPEAT repeatstart,repeatrate
----

Beispielsweise:

[source,basic]
----
OPTION KEYBOARD REPEAT 250,50
----

Die Wiederholung beginnt nach 250 ms und erfolgt anschließend alle 50 ms.

Je kleiner `repeatrate` gewählt wird, desto schneller werden die
Tastenwiederholungen erzeugt. Der kleinste zulässige Wert von 25 ms ergibt
bei einer USB-Tastatur somit die höchste Wiederholrate.

[TIP]
====
Wenn sich die Tastatur bei der Eingabe zu träge anfühlt, kann eine kürzere
Startverzögerung und insbesondere ein kleinerer Wert für `repeatrate` die
Bedienung deutlich angenehmer machen.
====

[IMPORTANT]
====
Für eine kontinuierliche Tastatursteuerung in Spielen ist eine hohe
Tastenwiederholrate trotzdem nicht die beste Lösung.

Dafür eignet sich `KEYDOWN()` besser. Damit kann ein Programm direkt
feststellen, ob eine Taste gerade gedrückt gehalten wird. Die Steuerung ist
dann unabhängig von der eingestellten Tastenwiederholrate.

Dieses Verfahren verwenden wir beispielsweise bei der Steuerung unseres
Pong-Spiels.
====

`OPTION KEYBOARD` muss an der MMBasic-Eingabeaufforderung eingegeben werden
und führt zu einem Neustart.

Die Tastaturkonfiguration kann wieder deaktiviert werden mit:

[source,basic]
----
OPTION KEYBOARD DISABLE
----

=== Was tun, wenn kein Bild mehr erscheint?

Da viele `OPTION`-Einstellungen dauerhaft gespeichert werden, kann eine
ungeeignete Einstellung auch nach einem Neustart erhalten bleiben.

Besonders bei VGA- und HDMI-Versionen kann es passieren, dass nach einer
Änderung der Auflösung, Bildwiederholrate oder des Grafikmodus kein Bild
mehr auf dem Monitor erscheint.

[IMPORTANT]
====
Ein schwarzer Bildschirm bedeutet nicht automatisch, dass der PicoMite
nicht mehr funktioniert.

Oft läuft MMBasic weiterhin und lediglich die Videoausgabe ist so
konfiguriert, dass der angeschlossene Monitor sie nicht darstellen kann.
====

==== Einen anderen Monitor ausprobieren

Wenn die Ursache eine nicht unterstützte Auflösung oder Bildwiederholrate
ist, kann bereits ein anderer Monitor helfen.

So war es beispielsweise beim Pico Computer 3: Ein Monitor konnte die mit

[source,basic]
----
OPTION RESOLUTION 640,315000
----

erzeugte Ausgabe mit 75 Hz darstellen, ein anderer dagegen nicht.

Über den funktionierenden Monitor konnte die Einstellung anschließend auf
60 Hz geändert werden:

[source,basic]
----
OPTION RESOLUTION 640,252000
----

==== Die Konsole als Rettungsweg

Wenn über VGA oder HDMI keine brauchbare Ausgabe mehr erscheint, kann die
MMBasic-Konsole einen zweiten Zugangsweg bieten.

Ist eine serielle Konsole konfiguriert und erreichbar, können dort die
gespeicherten Einstellungen zunächst überprüft werden:

[source,basic]
----
OPTION LIST
----

Anschließend kann die fehlerhafte Einstellung korrigiert werden.

[TIP]
====
Gerade beim Experimentieren mit permanenten `OPTION`-Einstellungen ist eine
funktionierende Konsolenverbindung ein nützlicher Rettungsweg. Damit lässt
sich der PicoMite häufig noch bedienen, obwohl die Bildschirmausgabe nicht
mehr funktioniert.
====

==== Konfiguration zurücksetzen

Sind mehrere Einstellungen verstellt oder ist die Ursache nicht mehr
bekannt, kann die Konfiguration zurückgesetzt werden.

Mit:

[source,basic]
----
OPTION RESET LIST
----

werden zunächst die für die verwendete Firmware verfügbaren
vordefinierten Konfigurationen angezeigt.

Anschließend kann eine passende Konfiguration geladen werden. Welche Namen
zur Verfügung stehen, hängt von der verwendeten Firmware ab.

[WARNING]
====
Bevor du `OPTION RESET` verwendest, solltest du wichtige Dateien des
internen Flashlaufwerks `A:` sichern.

Je nach verwendeter Firmware und Reset-Konfiguration kann ein
`OPTION RESET` nicht nur die gespeicherten Optionen zurücksetzen, sondern
auch das Flashlaufwerk `A:` löschen oder neu initialisieren.

Kopiere deshalb eigene BASIC-Programme, Konfigurationsdateien und andere
wichtige Daten vorher beispielsweise auf eine SD-Karte oder auf deinen
Computer.

Prüfe außerdem nach Möglichkeit zunächst mit `OPTION LIST` die aktuelle
Konfiguration und notiere wichtige Einstellungen.
====

`OPTION RESET` sollte deshalb als Rettungsweg erst verwendet werden, wenn
sich die fehlerhafte Einstellung nicht gezielt korrigieren lässt.

==== Wenn auch die Konsole nicht mehr erreichbar ist

Als letzter Rettungsweg kann die PicoMite-Firmware neu aufgespielt werden.
In besonders hartnäckigen Fällen kann zuvor auch der Flash-Speicher des
Pico vollständig gelöscht und die Firmware anschließend neu installiert
werden.

Das ist jedoch normalerweise erst notwendig, wenn sich die Konfiguration
nicht mehr über die MMBasic-Konsole korrigieren lässt.

=== OPTION RESET

Mit indexterm:[OPTION RESET] `OPTION RESET`:

[source,basic]
----
OPTION RESET
----

werden alle *gespeicherten* Optionen auf ihre Standardwerte zurückgesetzt.

[WARNING]
====
`OPTION RESET` löscht die zuvor dauerhaft gespeicherten Anpassungen der PicoMite-Konfiguration. Verwende den Befehl daher mit Bedacht.
====

`OPTION RESET` muss an der MMBasic-Eingabeaufforderung ausgeführt werden und kann nicht innerhalb eines Programms verwendet werden.

Temporäre programmbezogene Einstellungen wie `OPTION EXPLICIT`, `OPTION DEFAULT` oder `OPTION BASE` gehören nicht zu den dauerhaft gespeicherten Optionen, die mit `OPTION RESET` zurückgesetzt werden.

=== Vordefinierte Konfigurationen

Zusätzlich unterstützt MMBasic vordefinierte Konfigurationen.

Welche Konfigurationen die verwendete Firmware kennt, lässt sich mit indexterm:[OPTION RESET LIST] `OPTION RESET LIST` anzeigen:

[source,basic]
----
OPTION RESET LIST
----

anzeigen.

Anschließend kann eine der angezeigten Konfigurationen mit:

[source,basic]
----
OPTION RESET <cfg>
----

aktiviert werden. Dabei wird `<cfg>` durch den tatsächlich von `OPTION RESET LIST` angezeigten Namen ersetzt.

[TIP]
====
Die verfügbaren Konfigurationsnamen können von der verwendeten PicoMite-Firmware abhängen. Deshalb solltest du zuerst `OPTION RESET LIST` verwenden, anstatt einen Konfigurationsnamen aus einem anderen System zu übernehmen.
====

Solche vordefinierten Konfigurationen sind beispielsweise hilfreich, wenn ein PicoMite nach dem Flashen einer Firmware für eine bestimmte Hardware eingerichtet werden soll.

=== Wann sollte man OPTION-Befehle verwenden?

Das hängt von der Art der Option ab.

Programmbezogene Optionen wie:

[source,basic]
----
OPTION EXPLICIT
OPTION DEFAULT NONE
OPTION BASE 0
----

können bewusst am Anfang eines BASIC-Programms stehen und dessen Verhalten festlegen.

Permanente Optionen wie `OPTION TAB`, `OPTION COLOURCODE` oder verschiedene Hardwareoptionen gehören dagegen zur Konfiguration des Systems und werden normalerweise an der MMBasic-Eingabeaufforderung eingerichtet.

=== Tipps aus der Praxis

* Verwende `OPTION EXPLICIT`, um Tippfehler bei Variablennamen frühzeitig zu erkennen.
* Mit `OPTION DEFAULT NONE` kannst du zusätzlich eine ausdrückliche Typangabe erzwingen.
* Setze `OPTION BASE` immer vor der ersten Array-Deklaration.
* Verwende `OPTION CPUSPEED` nur auf PicoMite-Versionen, die diesen Befehl unterstützen.
* Dokumentiere Änderungen an permanenten Systemoptionen.
* Mit `OPTION LIST` kannst du geänderte permanente Einstellungen kontrollieren.
* Verwende vor `OPTION RESET <cfg>` zunächst `OPTION RESET LIST`.

=== Probier's selbst!

. Gib an der MMBasic-Eingabeaufforderung `OPTION LIST` ein.
. Schreibe ein kleines Programm mit `OPTION EXPLICIT` und einer absichtlich falsch geschriebenen Variablen.
. Teste anschließend `OPTION DEFAULT NONE` und lasse bei einer Variablen die Typangabe weg.
. Probiere `OPTION BASE 0` mit einem kleinen Array aus.
. Falls dein System einen Bildschirm oder ein geeignetes Terminal verwendet, probiere `OPTION COLOURCODE ON` aus.

=== Zusammenfassung

In diesem Kapitel hast du gelernt:

* dass es temporäre und permanent gespeicherte `OPTION`-Einstellungen gibt
* warum manche OPTION-Einstellungen vor dem Start eines Programms vorgenommen werden müssen
* geänderte permanente Einstellungen mit `OPTION LIST` anzuzeigen
* `OPTION EXPLICIT` zur Kontrolle von Variablendeklarationen einzusetzen
* mit `OPTION DEFAULT` den Standard-Datentyp festzulegen
* mit `OPTION BASE` den Startindex von Arrays zu bestimmen
* `OPTION TAB` und `OPTION COLOURCODE` anzupassen
* dass `OPTION CPUSPEED` nicht bei VGA- und HDMI-Versionen zur Verfügung steht
* dass VGA- und HDMI-Versionen ihre CPU-Taktfrequenz im Zusammenhang mit der Videoauflösung und Bildwiederholrate festlegen
* dass eine ungeeignete Bildwiederholrate dazu führen kann, dass ein Monitor kein Bild anzeigt
* mit `OPTION KEYBOARD` das Tastaturlayout und weitere Tastatureinstellungen festzulegen
* mit `OPTION KEYBOARD REPEAT` die Tastenwiederholung einer USB-Tastatur anzupassen
* gespeicherte Einstellungen mit `OPTION RESET` zurückzusetzen
* verfügbare vordefinierte Konfigurationen mit `OPTION RESET LIST` anzuzeigen

`OPTION`-Befehle sind damit sowohl ein Werkzeug für eine strengere und besser
kontrollierbare BASIC-Programmierung als auch für die Anpassung des
PicoMite-Systems an die verwendete Hardware und die eigenen Bedürfnisse.
